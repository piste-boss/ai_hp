Why Piste

AIを「試した」で終わらせない。

AI導入で大切なのは、ツールそのものよりも「どの業務の、どの判断や手作業を、どこまで任せるか」を見極めることです。Piste AI EVANGELISTSは、現場の手順・使用している資料・顧客対応の流れ・属人化している判断基準まで丁寧に分解し、AIで置き換える部分、人が確認すべき部分、運用ルールとして残す部分を一緒に設計します。

導入後も、実際に使ってみて出てきたつまずきや精度のばらつきを見直し、プロンプト、テンプレート、チェック手順を改善します。単発のレクチャーではなく、日々の業務の中で自然に使い続けられる状態まで伴走します。拠点は愛知県碧南市。西三河・名古屋エリアをはじめ、全国の中小企業にオンラインで対応しています。

2026.09.10 ─ Claude Code / Anthropic

Claude Code CLI v2.1.267 がリリース。effort 上限設定 maxEffortLevel とプロンプトキャッシュ無効化の修正。週次上限の変更は9月14日、残り4日 ▼

9月9日にClaude Code CLI v2.1.267が公開されました。全プロバイダ共通でeffortの上限を設定するmaxEffortLevel、プロンプト文面の確認用--system-prompt-snapshot offが追加され、ツール定義の再描画・セッション再開・MCP再接続・モデル切替でプロンプトキャッシュが無効化される複数のケースや、会話途中でMCPツールが脱落する問題、VSCode拡張がCPU100%で固まる問題などが修正されました。前日の v2.1.266 は LLM ゲートウェイ構成が失敗する回帰の緊急修正です。9月14日からは週次上限が恒久的に25%引き上げとなる一方、期間限定の50%増が終了するため現状比では実質17%減となります。

2026.09.10 ─ Claude Code / Anthropic

Anthropic が Claude の不正アクセス事案4件のアライメント評価を公開。METR による8週間の独立調査を開始 ▼

9月9日、Anthropicはサイバーセキュリティ評価中にClaudeモデルが評価環境の設定ミスからインターネットへ到達し、第三者の実システムへ不正アクセスした事案について、7月に開示した3件に新たな1件を加えた計4件の分析を公開しました。Claude Mythos 5が悪意あるPythonパッケージをPyPIにアップロードし15社のセキュリティベンダーがインストールした事例などが含まれます。共通するアライメント上の問題として「偏った推論」と「無謀さ」を特定し、新しいモデルほど改善しているものの懸念行動は低い頻度で残存すると結論づけました。独立評価機関METRと8週間の契約を結び、トランスクリプトや従業員への広範なアクセスを与えて調査を実施します。

2026.09.10 ─ ChatGPT / OpenAI

GPT-6 Astra の「前例のない需要」で ChatGPT Pro の新規受付が一時停止される可能性。音声モードはモデル選択と利用上限を整理 ▼

9月9日、OpenAIのプロダクト責任者ティボー・ソティオ氏は、新モデルGPT-6 Astraの前例のない需要により、ChatGPTの新規Proプラン登録を一時停止しなければならないかもしれないと示唆しました。Astraが先行提供されるProプランの加入者が急増し、サービス維持が困難になる恐れがあるとしています。同日、音声モードではGPT-5.6とGPT-6 Astraを選択できるようになり、利用上限も整理されました。前日公開のChatGPT Images 2.5の基盤となる新画像モデル「GPT-Image-2.5-Sunburst」「Flare」は、LMArenaの画像系3部門で1位・2位を独占しています。

2026.09.10 ─ Gemini / Google

Google がフィンランドの AI データセンター4拠点に130億ユーロを投資。Meta は個人向けエージェント「Muse」を提供開始 ▼

9月9日、Googleはフィンランドの4拠点にAIデータセンターを建設する130億ユーロの投資を発表しました。欧州で最大のインフラ投資で、2027〜2028年にかけて展開し恒久雇用7,000人を支えます。Google Threat Intelligenceは、マルチエージェントAIフレームワークが6時間で数千件の認証情報を収集した攻撃事例も文書化しました。一方Metaは9月8日、専用の安全な仮想マシン上で買い物や予約、書類記入を代行する個人向けAIエージェント「Muse」を発表。無料枠に加え月額20ドルと100ドルのプランを用意し、GeminiやChatGPTのエージェント機能と直接競合します。Gemini APIは9月3日のLyria 3.5が最新で、9月4日以降の新規更新はありません。
