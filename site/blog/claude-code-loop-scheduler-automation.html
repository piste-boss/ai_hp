「毎朝6時に売上データをまとめて、9時までにレポートを作る」「夜21時に翌日の予約情報をLINEに通知する」「週次の競合調査を月曜の朝一で仕上げる」——時間で区切られた定型業務は、必ず「誰かがその時間に動く」ことを前提にしています。経営者や一人社長が早朝に起きて作業したり、スタッフに残業を頼んだりしていませんか。

この問題を根本から解決するのが、Claude Codeの/loop（ループ機能）とCronCreate（スケジュール機能）です。Anthropic公式CLIであるClaude Codeには、2026年に入って「指定時刻に自動で処理を起動する」「一定間隔で繰り返す」という"常駐ワーカー"の仕組みが強化されました。AIが勝手に起き、仕事をして、また待機に戻る——そんな24時間運転の業務基盤が、非エンジニアでも構築できるようになっています。

この記事では、Claude Codeのスケジュール機能の仕組みと、中小企業での活用法、非エンジニアでも始められる4ステップを解説します。

1. /loopとスケジュール機能とは？"AI常駐ワーカー"が生まれる理由

Claude Codeの/loopは「同じコマンドを一定間隔で繰り返す」機能で、CronCreateは「指定の日時・曜日に自動起動する」機能です。2つを組み合わせると、AIがあらかじめ決めたスケジュールで勝手に業務を回し、結果を通知・記録する運用が可能になります。チャットのように人が呼び出す必要がなく、AIがタイマーに従って自分で起きてくる感覚に近いです。

従来の自動化との違い

  • RPAは画面を開きっぱなしにする必要があるが、Claude Codeはバックグラウンドで自動起動する
  • 業務スクリプトはエラー処理や通知機能を個別実装しなければならないが、Claude CodeはAIが状況を見て判断できる
  • 外部のワークフローサービス（Make・Zapier）に頼らなくても、AIが判断と実行を一体で担える

Hook・サブエージェントとの相性

/loopとCronCreateは単体でも便利ですが、Hook（イベント駆動）やサブエージェント（業務分担）と組み合わせると真価を発揮します。たとえば「毎朝7時に売上データを収集→専門サブエージェントに分析させる→結果をSlackに通知」といった複数工程を、一つのスケジュール起動で完結させられます。

2. 中小企業ではどんな業務をスケジュール自動化すると効果が出ますか？

(1) 早朝の売上・予約データ集計

毎朝6時〜7時に、前日の売上・予約・在庫データをまとめ、経営者のスマホに要約レポートを届ける運用が組めます。出社前に業績を把握できるため、朝礼の質が上がり、判断スピードが飛躍的に速くなります。データは会計・POS・予約システムなどから横断取得し、異常値があればコメント付きで報告します。

(2) 深夜の定期レポート・ブログ下書き作成

スタッフが退勤した後の深夜帯に、翌日以降のブログ原稿や社内レポートの下書きをAIが作成しておく運用です。出勤したときには「仕上げて公開するだけ」の状態で下書きが揃っており、朝の1時間が丸ごと浮きます。業務時間を侵食せずにコンテンツ量を増やせるのが最大の強みです。

(3) 週次の競合調査・市場動向サマリー

毎週月曜の朝、主要競合サイトの更新点・検索順位・SNS投稿動向をクロールして要約します。担当者が「月曜の朝イチでまとめる」習慣的な調査業務を、完全無人化できます。Claude Codeは結果の比較と差分検知もこなすため、変化が起きた項目だけを抜き出して報告させる設計も可能です。

(4) 毎晩の通知・リマインド配信

夜21時に「翌日の予約一覧」「仕込み・準備タスク」「明日の会議アジェンダ」を関係者のLINEやメールに送る運用が可能です。スタッフは自宅にいながら翌日の準備を把握でき、朝の出勤直後の混乱や抜け漏れが激減します。通知内容はAIが当日のデータを見て自動で組み立てます。

(5) 月次処理・請求書発行の自動化

毎月25日の夜間に、請求書の下書き作成・経費集計・月次報告書の初稿生成をAIが済ませておく運用です。月末・月初に集中する経理負担を夜間に分散でき、担当者は確認と最終送付だけに集中できます。会計ソフトと連携すれば、仕訳の初稿もあわせて準備させられます。

4. 非エンジニアが Claude Code のスケジュール実行を導入する4ステップは？

ステップ1：時間で区切られた業務を洗い出す

「毎朝この時間にやっている」「毎週月曜にまとめている」「月末に発行している」といった、時刻や曜日に紐づく業務を棚卸しします。5分で済むものから1時間かかるものまで書き出し、先に自動化すべきものを決めます。最初は「早朝の売上確認」「週次レポート」「月末の請求処理」の中から一つ選ぶと効果が見えやすいです。

ステップ2：Claude Codeに業務手順をスキルとして登録する

選んだ業務を「どのデータを見て」「どうまとめて」「誰に届けるか」まで日本語で書き出し、Claude Codeのスキル（スラッシュコマンド）として登録します。指示は操作ログを書くような感覚で十分で、エンジニア的な書き方は不要です。1度作ったスキルは名前を付けて呼び出せるため、再利用が効きます。通知先や社内ルールなどの決めごとはCLAUDE.mdにまとめておくと、毎回の実行で守られます。

ステップ3：/loopかCronCreateでスケジュールを設定する

登録したスキルを、一定間隔で繰り返すなら/loop、決まった時刻に起動するならCronCreateで時刻設定します。「毎朝7時」「毎週月曜9時」「毎月25日21時」など、日本語で指示するだけで予約完了です。初回は数日間、動作結果を確認しながら時刻を微調整すると安定します。

ステップ4：通知先とエラー対策を整える

自動実行の結果は、メール・Slack・LINE・社内Notionなど普段使いのツールに届けます。併せて「実行が失敗したら担当者に通知する」ルールを1つ決めておくと、放置事故を防げます。ここまで整えば、24時間運転の基盤が完成し、朝起きたときには業務の半分が終わっている状態になります。

5. 導入前に知っておくべき注意点

  • PCの常時稼働設計：スケジュール起動は端末が動いている必要があるため、事務所PCのスリープ設定を見直す
  • 重要操作の人確認：決済・送信・削除などの不可逆操作は、AIが準備まで行い最終送信は人が行う設計にする
  • 時刻の重複に注意：複数スケジュールが同時刻に重なると処理が競合するため、5〜10分ずらして配置する
  • ログの保管：自動実行の結果ログは一定期間保存し、異常時の追跡に使えるようにする
  • 祝日・休業日への対応：月次処理など営業日に依存するものはカレンダー連携で自動スキップさせる

6. よくある質問

Q1. PCを閉じていても動きますか？

Claude Code自体はローカルPCで動くため、PCが起動していてかつスリープから復帰できる状態である必要があります。事務所の据え置き機や常時起動のMac miniなどを母艦にするのが一般的です。クラウド上で動かしたい場合は、サーバー設置型の運用に拡張できます。

Q2. プログラミング経験がなくても使えますか？

使えます。業務手順を日本語で書き、AIに「毎朝7時に実行して」と指示するだけです。cron記法を覚える必要はなく、自然な時刻表現で登録できます。エラー時の対応もAIが提案してくれるため、試行錯誤しながら完成度を上げていけます。

Q3. 実行結果をどこで確認できますか？

メール・Slack・LINE・社内チャット・Notionなど、普段使っているツールに出力できます。要約だけ通知してログ全文は別に保管する、という構成が読みやすさと追跡性の両立に向いています。

Q4. 他の自動化ツールと併用できますか？

併用できます。起動トリガーはClaude Codeに任せ、一部の複雑な画面操作はPlaywrightや別の自動化ツールに委ねるなど、役割を分けると運用が安定します。既存のMake・Zapierと組み合わせて使っている事例も増えています。

Q5. 導入にどれくらい時間がかかりますか？

1業務だけなら打ち合わせから初回稼働まで2〜3時間程度が目安です。3業務を並行稼働させる場合でも半日〜1日でセットアップでき、月単位で数十時間の稼働削減につながることが多いです。
