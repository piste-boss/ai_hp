この記事の要点

  • 対象：事務所・工場・倉庫・店舗など複数の拠点に電気・ガス・水道の請求が届き、検針票・請求書・二か月に一度の納入通知書・ウェブの明細に分かれたまま帳簿では水道光熱費の一行にまとまって消え、拠点ごと月ごとに使った量と払った金額を一覧で見たことがない製造加工・飲食小売・介護医療・建設リフォーム・士業サービスなどの中小企業
  • できるようになること：散らばった記録を拠点ごと月ごとにそろえ（水道の二か月分は一か月ずつに割る）、金額を使用量で割った単価を出し、前年同月より増えた分を使用量の増加分と単価の上昇分に分け、春秋を基準にした夏冬の幅を去年と今年で並べて、使い方で減らせる分・契約でしか減らせない分・設備を替えないと減らない分を切り分け、検針票の置き場を決めて月に一度確かめる運用の判断材料をつくれる
  • 必要なもの：Claude Code と、過去二年分（残っている期間だけでも可）の電気の検針票かウェブの明細・ガスの請求書・水道の納入通知書、拠点ごとの契約の種類、帳簿の水道光熱費の合計（一覧との突き合わせ用）

「今月の電気代、去年より高い気がする」「工場と事務所と倉庫で、どこがいちばん使っているか分からない」「値上げのせいなのか、うちが使いすぎているのか、どちらなのか説明できない」。中小企業では、電気、ガス、水道の請求書が毎月届き、金額を見て「高いな」と思いながら支払って終わりになっています。ところが、拠点ごと、月ごとに、使った量と払った金額を一覧で並べて見たことがある会社はほとんどありません。電気は電力会社の検針票かウェブの明細、ガスはガス会社の請求書、水道は二か月に一度の納入通知書と、届く相手も周期も違い、帳簿では「水道光熱費」の一行にまとまって消えていきます。

その結果、何が起きるか。単価が上がって高くなったのか、使う量が増えて高くなったのかが分からないまま、「節電しよう」と社内に呼びかけて終わる。夏と冬に増えるのは当たり前なのに、その当たり前の幅がどれくらいなのかを誰も知らない。倉庫の電気が夜も点いているのか、古い空調が効率を落としているのかは、金額の合計からは見えない。光熱費の本当の問題は、金額が高いことではなく、使った量と単価と季節の三つを分けて並べたことがないため、手を打てるところと打てないところの区別がつかないことです。

この記事では、Anthropic社の公式AIコーディングツール Claude Code を使って、検針票、請求書、納入通知書、ウェブの明細に散らばった電気・ガス・水道の記録を拠点ごと月ごとの一覧にそろえ、使った量と払った金額と一単位あたりの単価を並べ、使いすぎで増えた分と単価の上昇で増えた分を分けて見る材料を整えるまでの手順を、非エンジニアの方向けに整理します。設備を替えるか、契約を見直すか、使い方を変えるかを決めるのは人の判断。機械に任せるのは、散らばった記録を集めて、拠点と月でそろえて、量と単価に分けて並べる作業です。

光熱費が「見えない」3つの理由

見えないのは、経理の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

1. 三つの相手から、三つの周期で、別々の紙が届く

電気は毎月、ガスも毎月、水道は二か月に一度。届く相手も紙の形も違い、電気は契約の種類ごとに請求が分かれることもあります。同じ一か月の光熱費が、三つの相手から違う周期で届き、帳簿では水道光熱費という一つの科目にまとまって入ります。帳簿は合計を見せてくれますが、どの拠点のどの月に、何がどれだけ増えたかは教えてくれません。

2. 「使った量」が請求書の隅にしか書かれていない

請求書でまず目に入るのは金額です。電気なら使用量のキロワット時、ガスなら立方メートル、水道なら立方メートルの数字は、紙の隅か明細の二枚目にあります。量を見ないまま金額だけを見ていると、単価の上昇と使いすぎの区別がつきません。前年より二割高い電気代は、単価が二割上がったのなら使い方の問題ではなく、量が二割増えたのなら使い方の問題です。

3. 季節の「当たり前の幅」を誰も知らない

夏の空調と冬の暖房で光熱費が増えるのは当たり前です。しかし、自社の夏が春のどれくらい増しなのか、去年の夏と今年の夏で同じ幅なのかを数字で知っている会社はほとんどありません。当たり前の幅が分かっていないと、当たり前の増え方と、何かがおかしい増え方を分けられず、毎年夏に「高い」と言って終わります。

光熱費が見えないのは、三つの相手から違う周期で紙が届き、使った量が隅にしか書かれておらず、季節の幅を知らないからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

機械に任せる範囲と、人が決める範囲

大前提として、設備を替えるか、契約を切り替えるか、使い方の決まりを変えるか、どの拠点から手をつけるかは会社の運営の判断であり、人が決めることです。機械に任せるのは、散らばった記録を集めて拠点と月でそろえ、量と金額と単価を横に並べ、比べられる形にするところまでです。

境界線は「並べる」と「決める」の間にあります。機械が出すのは、拠点ごと月ごとの量と単価の並びと、増え方がおかしい拠点の印までです。その先の、設備に投資するか、使い方を変えるかの線は、人が引きます。

実務5ステップ

ステップ1：過去二年分の検針票と請求書を洗い出す

電気の検針票かウェブの明細、ガスの請求書、水道の納入通知書を、拠点ごとに二年分集め、Claude Codeに「この二年の電気・ガス・水道を拠点ごと月ごとの一覧にし、使用量・金額・契約の種類を並べてほしい」と頼みます。一年分では季節の比較ができないため、二年分が最初の単位です。紙が見つからない月は、空欄のまま残させます。空欄が多い拠点ほど、記録の置き場が決まっていない拠点です。空欄そのものが、最初の発見になります。

ステップ2：拠点名と期間をそろえる

同じ場所が「本社」「事務所」「一階」のように三通りで呼ばれていたり、検針の期間が月の途中から途中までだったりします。拠点の呼び名を一つにそろえ、検針期間を月に読み替え、二か月分で届く水道は一か月ずつに割って、月の単位をそろえます。あわせて、事務所・工場・倉庫・店舗・寮のような拠点の種類をつけます。種類が違う拠点どうしを比べても、多い少ないに意味がないからです。

ステップ3：単価を出し、増えた分を「量」と「単価」に分ける

一覧を拠点ごと種類ごとにまとめ、金額を使用量で割って月ごとの単価を出します。前年同月より増えた金額を、使用量が増えたことで増えた分と、単価が上がったことで増えた分に分けます。この切り分けが、光熱費を見る物差しになります。単価の上昇で増えた分は使い方では減らせず、契約の見直しでしか手が打てません。使用量の増加で増えた分は、使い方と設備で手が打てます。同じ「二割高い」でも、打つ手がまったく違います。

ステップ4：季節の幅を出し、おかしい増え方を分ける

春と秋の平均を基準にして、夏と冬がそれぞれ何割増しかを拠点ごとに出し、去年と今年で並べます。去年の夏が春の四割増しで、今年の夏が七割増しなら、暑さの差を差し引いても何かが変わった拠点です。空調の効率が落ちたか、稼働の時間が延びたか、使い方が変わったかのどれかです。逆に、季節に関係なく毎月じわじわ増えている拠点は、夜間や休日に何かが動いたままになっている拠点です。ここで初めて、「倉庫の電気は冬より夏が増えるはずなのに、去年の秋から毎月増えている」「二階の事務所だけ単価が他より一割高い契約のままだった」という形が見えます。

ステップ5：検針票の置き場を決め、月に一度だけ確かめる

一覧ができたら、届いた検針票と請求書を拠点ごとの一つの置き場に入れる、あるいはウェブの明細を月初に一度保存するという一つの決まりだけつくります。月に一度、その月の拠点ごとの使用量と単価を出させ、前年同月より使用量が二割以上増えた拠点と、単価が上がった契約を出させます。細かい運用にすると続きません。一か月に一度、十五分で終わる形にします。

頼み方の3原則

原則1：「光熱費」に何を含めるかを、こちらから言葉で決める

電気・ガス・水道は分かりやすいですが、灯油や重油、プロパンのボンベ、給湯の契約、店舗の共益費に含まれる電気、自販機の電気、社員寮の分を含めるかどうかで数字は変わります。機械に任せる前に、含めるものと含めないものをこちらから指定します。おすすめは、その拠点を動かすのに使ったエネルギーをすべて含めることです。含めない物が多いほど、実態より少なく見えます。

原則2：使用量は「検針票にある数字」で書かせ、推測で埋めさせない

紙が見つからない月を、機械は「前後の月から平均して」埋めたがります。記録にない使用量は空欄のまま残させ、推測で埋めさせません。推測で埋めた一覧は、季節の幅が整って見える分だけ、増え方の異常を見逃します。空欄は、次に紙を探す場所を教えてくれる印です。

原則3：一覧の合計と、帳簿の水道光熱費を突き合わせる

一覧に並んだ金額の合計が、帳簿の水道光熱費の合計と合っているかを突き合わせさせます。合計が帳簿より小さい場合、集めきれていない請求書があります。たいていは、別の科目に入っている灯油代か、家賃と一緒に払っている共益費の中の電気です。差額の出どころを探すことが、記録の穴を見つける近道になります。

つまずきやすい5つの型

型1：金額だけ見て、使用量を見ない

前年より金額が高い月を「問題の月」と決めがちですが、単価が上がっていれば金額が上がるのは当たり前です。金額と使用量と単価の三つを並べて見ます。金額は増えているのに使用量は減っている拠点は、使い方の努力が単価の上昇に打ち消されているだけで、責める相手はいません。

型2：種類の違う拠点どうしを比べる

工場と事務所を電気の使用量で比べても、意味のある差は出ません。同じ種類の拠点どうし、あるいは同じ拠点の去年と今年で比べます。種類をつけずに全拠点を一列に並べると、多い拠点と少ない拠点が分かるだけで、次の手が決まりません。

型3：水道の二か月分を、そのまま一か月に置く

水道は二か月に一度の請求のため、そのまま並べると二か月に一度だけ跳ね上がる月ができます。二か月分は一か月ずつに割って、電気やガスと同じ月の単位にそろえます。そろえ直しは地味ですが、飛ばすと季節の幅も前年比も全部ずれます。

型4：夏と冬の増加を、全部「季節のせい」にする

夏に増えるのは当たり前だからと、夏の数字を見ずに済ませると、空調の効率が落ちたことに気づけません。季節の幅を去年と今年で並べ、幅が広がった拠点だけを見ます。当たり前の増え方の中に、当たり前でない増え方が隠れています。

型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱり倉庫が多い」と納得して終わると、次の月も同じお金が出ていきます。月に一度、検針票の置き場か、夜間の消し忘れの確認か、一つでよいので決まりを変えます。変えた決まりが、次の月の数字の根拠になります。

業種別の効きどころ

業種効きどころ
製造・加工工場の電気を月の稼働日数で割って一日あたりにし、稼働が減った月に使用量が減っていない設備を見つける。休日に動いたままの機械やコンプレッサーの確認に使う
飲食・小売店舗ごとのガスと電気を売上と並べ、売上が減っても使用量が減らない店を見つける。冷蔵設備の老朽化と営業時間外の消し忘れを分ける材料にする
介護・医療施設ごとの水道と給湯を利用者数で割り、一人あたりの使用量が増えた施設を見つける。漏水の早期発見と設備更新の順番決めに使う
建設・リフォーム事務所と資材倉庫と現場事務所の電気を分け、現場が終わっても契約が残ったままの拠点を見つける。仮設の契約の解約漏れの確認に使う
士業・サービス事務所の電気を在席の人数で割り、在宅勤務の日が増えても使用量が減らない月を見つける。空調の設定と点けっぱなしの機器の見直しに使う

どの業種でも共通するのは、帳簿で一行にまとまっていた光熱費を、拠点ごとの使用量と単価と季節の幅という三つの物差しで並べ直すことです。並べ直すと、使い方で減らせる分と、契約でしか減らせない分と、設備を替えないと減らない分が分かれて見えてきます。

よくあるご質問

拠点が一つでも必要ですか

拠点が一つでも、電気・ガス・水道の三つと二年分の月で七十行ほどの一覧になり、最初の一覧づくりは半日で終わります。拠点が一つのうちに検針票の置き場と月に一度の確認の決まりをつくっておく方が、拠点が増えたときに楽です。

検針票を捨ててしまっていて、二年分がそろいません

電力会社やガス会社のウェブの明細には、過去一年から二年分の使用量が残っていることが多くあります。まずそこから拾い、ないものは帳簿の金額だけを並べ、使用量は空欄で残します。過去は金額だけ、これからは量と金額の両方、で十分です。

自社ビルではなく、家賃に電気代が含まれている場合はどうしますか

家賃の中の電気代は、貸主からの明細に使用量が書かれていればそれを拾い、金額だけの場合は金額のみを並べます。含まれている分はその旨を項目の欄に残させ、自社で契約している分と分けて集計します。混ぜると単価が出せなくなります。

どれくらいの時間がかかりますか

二年分の検針票と請求書を渡して最初の一覧が出るまでは、拠点の数にもよりますが一時間ほどです。拠点名と期間のそろえ直しと帳簿との突き合わせに数日、そのあとは月に一度、その月の拠点ごとの使用量と単価を出させて確かめるだけです。
