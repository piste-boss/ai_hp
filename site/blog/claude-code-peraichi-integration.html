1. なぜ「ペライチ × Claude Code」なのか

ペライチは、専門知識がなくてもブロックを並べるだけで1ページ完結のランディングページ（LP）やホームページが作れるサービスです。手軽な一方で、実際に手を動かすと「キャッチコピーが思いつかない」「サービス説明が長くなりすぎる」「お客様の声をどうまとめるか分からない」といった、文章とコンテンツづくりの部分で多くの人が止まってしまいます。

Claude Codeは、こうした「考えて・書いて・整える」作業を日本語の指示だけでAIに任せられるツールです。ペライチに載せる原稿づくりや構成案、公開後の改善提案までを横断的にサポートできます。プログラミングの知識は不要で、やりたいことを言葉で伝えるだけです。つまり、ペライチという「自分で組み立てられるページの箱」に対して、Claude Codeを「Webライター兼ディレクター」として配置するイメージです。

2. Claude Codeとは？（おさらい）

Claude Codeは、AI開発企業Anthropicが提供するAIコーディングツール（CLI）です。最大の特徴は、専門用語を覚えなくても「〇〇して」と日本語で頼むだけで、文章作成・情報整理・構成立案・ブラウザ操作までこなしてくれる点にあります。

  • ノーコードに近い操作感：コードを書かずに業務指示が出せる
  • 外部サービスとの連携：ブラウザ操作などで他ツールとつながる
  • 繰り返し作業の自動化：一度作った手順を何度でも再利用できる

ペライチ単体では「作る場所」は手に入りますが、「何を書くか」は自分で考える必要があります。そこをClaude Codeが補うことで、ページづくりのいちばん重い部分が一気に軽くなります。

3. Claude Code はペライチのページ作成で何ができますか？

① ページ構成案とキャッチコピーの自動作成

商品・サービスの情報を伝えるだけで、ペライチのブロック構成に沿った「見出し→説明→お客様の声→料金→申し込み」といった流れと、目を引くキャッチコピー案を複数生成します。ゼロから書き始める負担がなくなります。

② サービス説明・プロフィール文の量産

箇条書きのメモを渡すだけで、読みやすく整った紹介文に仕上げます。トーン（やわらかい／信頼感重視など）を最初に決めておけば、ブランドの世界観を保ったまま各ブロックの文章を一括で用意できます。

③ よくある質問（FAQ）と申し込み導線の設計

想定される問い合わせを洗い出してFAQ形式にまとめ、申し込みボタンの文言や配置のアイデアまで提案します。「迷わせない・離脱させない」ページ設計を、データと定石の両面からサポートします。ページからネットショップや予約受付につなげたい場合は、STORESとの連携で受注や予約の対応まで同じ流れで整えられます。

④ 公開後のページ改善・リライト提案

すでに公開しているページの内容を読み取り、「説明が長い」「強みが伝わりにくい」といった改善点を指摘し、書き換え案を提示します。作りっぱなしになりがちなページを、定期的にブラッシュアップできます。ページへの入口を増やす発信を続けたい方は、noteとの連携で記事作成を効率化する方法も参考になります。

⑤ キャンペーン・季節ページの一括作成

セールや季節イベントに合わせた告知ページの原稿を、テーマを伝えるだけでまとめて作成します。繁忙期前に複数パターンを用意しておけば、タイミングを逃さず公開できます。

5. 非エンジニアはどんな手順で導入すればよいですか？

  1. 目的を1つに絞る：まずは「サービス紹介LPの原稿を作りたい」など、効果が見えやすいページを一つ選びます。
  2. Claude Codeを用意する：PCにClaude Codeを導入し、「どんなお客様に・何を伝えたいか」を日本語で伝えられる状態にします。
  3. つなぎ方を決める：原稿づくりはClaude Codeで行い、ペライチへの貼り付けは手作業から始めると安全です。慣れてきたらブラウザ操作で更新作業まで広げます。
  4. 小さく試して広げる：1ページでうまく回ったら、FAQ作成・改善提案・キャンペーンページ量産へと対象を増やしていきます。

大切なのは、いきなり全自動化を狙わず、「まず一つのページを確実に完成させる」こと。小さな成功体験が、Web集客への自信と継続につながります。

6. 運用上の注意点

  • 認証情報の管理：ペライチのログイン情報は、誰でも見られる場所に置かず、安全に保管します。
  • 公開前は必ず人が確認する：料金・申し込み条件・特典など重要な情報は、AIに下書きまで任せ、最終チェックは人が行う設計にします。
  • 事実と異なる表現に注意：実績や効果をうたう文章は、誇張や不正確な記載がないか確認し、景品表示法など関連ルールに配慮します。
  • ペライチの利用規約を確認：自動操作が規約に反しないか、事前に確認しておくと安心です。
  • ブランドの一貫性：作った文章のトーンや言い回しのルールを記録に残し、ページが増えても世界観がぶれないようにしておきます。

7. よくある質問（FAQ）

Q. プログラミングができなくても使えますか？

はい。Claude Codeは日本語で指示を出すだけで動くため、コードを書く必要はありません。「このサービスのLP原稿を作って」といった頼み方で十分です。

Q. すでにペライチで作ったページがあります。活かせますか？

活かせます。既存ページの内容を読み取り、改善点の指摘やリライト案の作成から始められるので、ゼロから作り直す必要はありません。

Q. どのくらいの作業から始めるのがおすすめですか？

まずは「1ページ分の原稿作成」から始めるのがおすすめです。効果を実感しやすく、その後の改善や量産にもスムーズに広げられます。

Q. 文章のトーンを自社らしく保てますか？

保てます。最初に希望するトーンや言い回しのルールを伝えておけば、ブランドの世界観を保ったまま各ページの文章を作成できます。
