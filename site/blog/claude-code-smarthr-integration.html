この記事の要点

  • 対象：人事労務を一人または社長が兼任している中小企業
  • できるようになること：入退社手続きの準備・勤怠集計・年末調整の進捗確認・労務通知の下書きをClaude Codeに任せる流れがわかる
  • 必要なもの：Claude Code、SmartHRのAPIアクセストークン、自社の就業規則・手続きフローのメモ

「入社のたびに同じ書類を手入力している」「年末調整の時期は人事担当が完全に止まる」「勤怠データの集計と給与ソフトへの転記だけで毎月数日かかる」——人事労務を一人、あるいは社長が兼任している中小企業ほど、この負担は重くのしかかります。本記事では、Anthropic公式のAIコーディングツール「Claude Code」と労務管理クラウド「SmartHR」を連携させ、入退社手続き・年末調整・勤怠集計・労務書類作成までを一括自動化する方法を解説します。プログラミングの知識がなくても運用できる仕組みです。

1. Claude Code × SmartHR連携で何が自動化できますか？

Claude Codeはターミナル上で動くAIコーディングツールで、自然言語で業務指示を出すと、API呼び出しやファイル操作、書類生成までこなしてくれます。SmartHRの公式APIと組み合わせることで、次のような人事労務作業がほぼ全自動になります。

  • 新入社員の情報を伝えるだけで、SmartHRへの従業員登録と必要書類の依頼を自動セットアップ
  • 入退社時の社会保険・雇用保険の手続きに必要な情報を自動で整理
  • 勤怠データを取得し、残業時間・有給消化状況を自動集計してレポート化
  • 年末調整の進捗（誰が未提出か）を自動チェックし、リマインド文面を作成
  • 労務関連の通知文・案内文を社内トーンに合わせて自動下書き

「まずは入退社手続きの抜け漏れをなくしたい」というニーズから「勤怠と給与計算の連携まで自動化したい」という高度な運用まで、同じ仕組みで段階的に拡張できます。

2. なぜ中小企業の人事労務に自動化が必要なのか

人事労務は「ミスが許されないのに、繁忙期に集中する」特殊な業務です。担当が一人だと、その人が不在になった瞬間に業務が止まるリスクもあります。

業務手作業の場合自動化後
入社手続き（1名）書類準備・登録で90〜120分情報整理と登録依頼で15分
勤怠データ集計毎月半日〜1日自動集計レポートで数分
年末調整の進捗管理未提出者の確認・督促で数日自動チェック＋リマインド文生成
労務書類の作成1件あたり30〜60分テンプレ自動生成で5分

少人数の会社こそ、この時間圧縮と「属人化の解消」の効果が大きく、担当者が変わっても同じ品質で業務を回せるようになります。

3. SmartHR連携を始めるには何を準備すればいいですか？

3-1. SmartHR側の準備

  • SmartHRアカウント（プランに応じてAPIアクセスを有効化）
  • APIアクセストークンの発行（管理者権限の設定画面から取得）
  • 従業員データベース・カスタム項目の整備
  • 権限設定（取得・更新できる範囲を必要最小限に限定）

3-2. Claude Code側の準備

  • 公式CLIのインストール
  • 作業ディレクトリに人事労務用フォルダを作成
  • 環境変数ファイルにアクセストークンを保存（権限は本人のみに制限）
  • 自社の就業規則・手続きフロー・書類テンプレートをまとめたメモリファイルを作成

3-3. 役割分担

担当内容
人間方針決定、内容の最終確認、提出・申請の承認
Claude Code情報整理、API操作、データ集計、書類・文面の下書き
SmartHR従業員データ管理、電子申請、書類の収集・保管

4. 具体的な活用シーン7選

シーン1：入社手続きのワンストップ準備

「来月1日付で1名入社、職種は営業」とClaude Codeに伝えると、SmartHRへの従業員登録、本人への入力依頼項目の整理、必要書類チェックリストの作成までを一気に準備します。担当者は内容を確認して送信するだけです。

シーン2：退社手続きの抜け漏れ防止

退職予定者が出た際に、社会保険の資格喪失・備品返却・アカウント停止などのToDoを自動でリスト化。手続き漏れによるトラブルを未然に防ぎます。

シーン3：勤怠データの自動集計とアラート

SmartHRや連携している勤怠データを取得し、残業が一定時間を超えた従業員、有給消化が進んでいない従業員を自動で抽出。労務リスクを早期に発見できます。抽出結果をDiscord などのチャットへ通知する仕組みと組み合わせると、担当者が見落としにくくなります。

シーン4：年末調整の進捗管理と督促文の作成

年末調整シーズンに「誰が未提出か」を自動チェックし、対象者への丁寧なリマインド文面を作成。担当者は送信先を確認するだけで済みます。

シーン5：労務通知・社内案内の自動下書き

就業規則の改定通知、健康診断の案内、各種手続きのお知らせなどを、自社のトーンに合わせて下書き。毎回ゼロから書く手間がなくなります。

シーン6：従業員データの定期レポート化

従業員数の推移、入退社の動向、部署別の人員構成などを月次レポートとして自動生成。経営判断や採用計画の材料になります。レポートをNotion の社内Wikiに蓄積しておくと、経営陣がいつでも参照できます。

シーン7：他システムとのデータ連携

会計ソフトや勤怠ツール、給与計算ソフトと組み合わせ、従業員情報を一元的に同期。同じ情報を複数のシステムに二重入力する作業をなくせます。

5. 自動化フローのサンプル構成

  1. 入社情報の受け取り（氏名・入社日・職種・雇用形態）
  2. SmartHRへの従業員登録と入力依頼の準備
  3. 必要書類チェックリストの自動生成
  4. 人間による内容確認
  5. 本人への依頼送信（承認後）
  6. 提出状況の自動追跡とリマインド文作成

このフローを1つのスキルとして登録しておけば、「新入社員の手続き準備して」とClaude Codeに伝えるだけで、ステップ1〜3が自動進行します。

6. 導入時に押さえるべきポイント

  • 個人情報の取り扱い範囲を限定：APIで取得する項目を必要最小限に絞り、権限設定を厳格にする
  • アクセストークンの安全な管理：環境変数ファイルに保存し、ファイル権限を本人のみに制限する
  • 申請・提出は承認制にする：下書き・準備まで自動、最終提出は人が承認する運用にする
  • 就業規則をメモリ化：自社ルールをAIに記憶させ、毎回ぶれない対応にする
  • 専門判断は社労士に：複雑な労務判断はAIに任せず、必ず専門家に確認する
完全自動化ではなく「準備・整理まで自動・申請は人が承認」という運用が、ミスを抑えつつ業務時間を大幅短縮する最適バランスです。

7. よくある質問

Q. プログラミングが全くできなくても使えますか

はい。Claude Codeは自然言語で指示するため、コードを書く必要はありません。最初の設定だけサポートを受ければ、その後は普通の会話で運用できます。

Q. SmartHR以外の労務ソフトでも同じことができますか

APIが公開されている労務・勤怠・給与計算ツールであれば、同様の連携が可能です。ツール選定からご相談いただけます。

Q. 個人情報の取り扱いは大丈夫ですか

従業員データはSmartHR側で管理され、Claude Codeには業務に必要な範囲のみが渡される設計にできます。権限・ログ管理も標準でサポートされています。

Q. 月にどれくらいの工数削減になりますか

従業員規模にもよりますが、入退社・勤怠集計・各種通知を合わせて月10時間前後の削減が見込めるケースが多いです。年末調整シーズンはさらに効果が大きくなります。
