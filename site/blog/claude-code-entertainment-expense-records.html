この記事の要点

  • 対象：接待や贈り物の費用が飲食店の領収書、贈答品の控え、ゴルフ場の明細、慶弔の記録、会社カードの明細に分かれ、帳簿では接待交際費の一行にまとまって消え、相手ごとの費用と取引の動きを一覧で見たことがない建設リフォーム・製造加工・卸商社・士業コンサル・飲食小売などの中小企業
  • できるようになること：散らばった記録を相手先ごとにまとめ直し、会食・贈答・ゴルフや催し・慶弔・手土産の種類をつけ、相手先ごとの年間の合計をその相手からの売上や粗利と並べ、一年間の注文の動きと突き合わせて続ける付き合いと見直す付き合いを分け、精算に相手先と用件の欄を足して月に一度確かめる運用の判断材料をつくれる
  • 必要なもの：Claude Code と、過去一年分の飲食店の領収書・贈答品の控え・ゴルフ場や催しの明細・慶弔の記録・会社カードの明細・小口の支出記録・社内の予定表、相手先ごとの売上や受注・見積もり依頼の記録、帳簿の接待交際費の年間合計（一覧との突き合わせ用）

「今年は接待や贈り物にいくら使ったのか、決算書の一行でしか分からない」「あの取引先には毎年お中元とお歳暮を送っているが、最近は注文が来ていない気がする」「会食の領収書は残っているが、誰と何の話をしたのかは社長の頭の中にしかない」。中小企業では、取引先との付き合いにかかった費用が、飲食店の領収書、百貨店の贈答品の控え、ゴルフ場の明細、慶弔の記録、会社カードの明細に分かれ、帳簿では「接待交際費」の一行にまとまって消えていきます。どの相手に、一年でいくら使い、その相手との取引がどう動いたのかを一覧で見たことがある会社は、ほとんどありません。

その結果、何が起きるか。決算のときに接待交際費が去年より増えていることに気づいても、どの相手への付き合いが増やしたのか説明できない。先代のころから続く贈り物が、注文の途絶えた相手にも毎年届き続ける。逆に、これから伸ばしたい相手には、付き合いの費用がほとんど使われていない。交際費の本当の問題は、金額が多いか少ないかではなく、相手ごとの費用と取引の動きを並べて見たことがないため、効いている付き合いと惰性の付き合いを分けられないことです。

この記事では、Anthropic社の公式AIコーディングツール Claude Code を使って、領収書、贈答品の控え、慶弔の記録、会社カードの明細、社内の予定表に散らばった付き合いの記録を相手先ごとの一覧にそろえ、費用と取引の動きを並べ、続ける付き合いと見直す付き合いを見分ける材料を整えるまでの手順を、非エンジニアの方向けに整理します。どの相手との付き合いを続けるか、贈り物をやめるか、会食の頻度を変えるかを決めるのは人の判断。機械に任せるのは、散らばった記録を集めて、相手先ごとにそろえて、費用と取引の動きに分けて並べる作業です。

交際費が「見えない」3つの理由

見えないのは、経理の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

1. 一つの相手への費用が、五つの記録に分かれる

同じ取引先への付き合いでも、会食は飲食店の領収書、お中元とお歳暮は百貨店の控え、ゴルフはゴルフ場の明細、慶弔は香典や祝いの記録、手土産は日々の小口の支出と、記録の置き場所が全部違います。支払った人も、支払い方も、帳簿の科目まで違うことがあるため、一つの相手に一年でいくら使ったかは、五つを突き合わせないと組み上がりません。会社のカードで払った分と社長の財布から出た分が混ざると、そもそも帳簿に載っていない付き合いの費用まであります。

2. 「誰と、何のために」が、領収書のどこにも書かれていない

税務のために領収書の裏に相手の名前を書く決まりはあっても、書かれているのは会社名と人数までです。何の話をしたのか、その後に見積もりの依頼や注文につながったのかは、どこにも残っていません。会食の席で聞いた話や、贈り物への返事は、行った本人の記憶の中にしかなく、会社の判断材料になっていないのです。

3. 続けるかどうかの基準がなく、前例と義理で決まる

去年も送ったから今年も送る、先代からの付き合いだから続ける、向こうから招かれたから招き返す。付き合いの多くは、費用と取引を比べたうえではなく、前例と義理で決まっています。基準がないため、やめる理由も続ける理由も説明できず、経費を削るときには一律に何割減という形になりがちで、本当に効いている付き合いまで削ってしまいます。

交際費が見えないのは、一つの相手への費用が五つの記録に分かれ、誰と何のためにがどこにも書かれず、続けるかどうかの基準が前例と義理で決まっているからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

機械に任せる範囲と、人が決める範囲

大前提として、どの相手との付き合いを続けるか、贈り物をやめるか、会食の回数を変えるか、義理をどこまで守るかは会社の運営の判断であり、人が決めることです。機械に任せるのは、散らばった記録を集めて相手先ごとにそろえ、費用と取引の動きを横に並べ、比べられる形にするところまでです。

工程担当内容
記録の収集機械飲食店の領収書・贈答品の控え・ゴルフ場や催しの明細・慶弔の記録・会社カードの明細・小口の支出記録・社内の予定表から、日付・相手・人数・金額・用件の記載を拾い出す
相手先ごとのまとめ直し機械会社名の表記ゆれや担当者名だけの記録を同じ相手にそろえ、五つの記録に分かれた費用を一つの相手の下にまとめる
一覧化機械日付・相手先・種類・人数・金額・用件・出席した自社の人を一行にそろえる
種類づけ機械会食・贈答・ゴルフや催し・慶弔・手土産の五つ前後の種類に分ける
費用の集計機械相手先ごと、種類ごと、月ごとに、一年間の回数と合計と一回あたりの金額を出す
取引の突き合わせ機械相手先ごとの一年間の売上や粗利、見積もりの依頼の回数を受注の記録から拾い、付き合いの費用の横に並べる
偏りの検出機械付き合いの費用が売上に対して同種の相手の平均より重い相手、一年間注文がないのに贈答が続いている相手、これから伸ばしたいのに費用がゼロの相手に印をつける
見直し案の下書き機械印のついた相手について、続ける・回数を減らす・贈答だけにする・やめるの四つの案と、それぞれの年間の費用の差を並べる
続けるか見直すかの判断人どの相手との付き合いを続けるか、義理をどこまで守るか、これからどこに費用を使うかを決める

境界線は「並べる」と「決める」の間にあります。機械が出すのは、相手先ごとの費用と取引の動きの並びと、偏りの印までです。その先の、義理を守って続けるか、そろそろやめるかの線は、人が引きます。

実務5ステップ

ステップ1：過去一年分の付き合いの記録を洗い出す

飲食店の領収書、贈答品の控え、ゴルフ場や催しの明細、慶弔の記録、会社カードの明細、小口の支出記録、社内の予定表を一年分集め、Claude Codeに「この一年の接待交際費を相手先ごとの一覧にし、費用と用件を並べてほしい」と頼みます。お中元とお歳暮、年末の会食のように季節の偏りがあるため、一年分が最初の単位です。相手の名前が書かれていない領収書は、空欄のまま残させます。空欄の多さそのものが、記録の流れのどこが抜けているかを教えてくれます。

ステップ2：相手先ごとにまとめ、種類をつける

同じ相手が、領収書では会社名、贈答の控えでは担当者の個人名、予定表では略称と、三つの書き方で記録されています。表記のちがう記録を同じ相手の下にまとめ、一年の合計を出します。あわせて、会食・贈答・ゴルフや催し・慶弔・手土産のように種類をつけます。種類が違えば一回あたりの金額の当たり前も違うため、種類をつけずに並べると、高い安いに意味がなくなります。慶弔は義理として残す性質が強いので、他の種類と分けておくことが大切です。

ステップ3：相手先ごとの年間の合計を、取引の大きさと並べる

一覧を相手先ごとにまとめ、一年間の回数と合計を出したら、その相手との一年間の売上や粗利を横に置きます。付き合いに使った費用が、その相手からの粗利の何割にあたるかが、付き合いを見る物差しになります。一回の会食が安くても毎月なら大きな額になり、年に一度の贈答でも注文のない相手なら重い額です。回数と一回あたり、そして相手からの取引の大きさを分けて見ると、減らすなら回数なのか、種類なのか、相手そのものなのかが見えてきます。

ステップ4：取引の動きと並べ、続ける付き合いと見直す付き合いを分ける

受注の記録や見積もりの依頼の記録を横に置き、この一年でその相手からの注文が増えたか、減ったか、途絶えたかに印をつけます。取引が動いている相手への付き合いは続ける候補、一年間注文がないのに贈答が続いている相手は見直す候補です。ただし、金融機関や地域の団体、仕入先のように、注文の有無で測れない相手もいます。ここで初めて、「A社には年に六回会食しているが、この一年で見積もりの依頼は一度もない」「これから伸ばしたいB社には、手土産一つ持って行っていない」という形が見えます。

ステップ5：領収書に用件の欄を一行足し、月に一度だけ確かめる

一覧ができたら、精算のときに「相手先」と「用件」を一行書くという一つの決まりだけつくります。月に一度、その月の付き合いを一覧に足させ、相手先ごとの累計と印のついた相手を出させます。細かい報告書にすると続きません。一か月に一度、十五分で終わる形にします。お中元とお歳暮の前には、贈る先の一覧を機械に出させ、見直す候補に印がついていないかを確かめてから発注します。

頼み方の3原則

原則1：「付き合いの費用」に何を含めるかを、こちらから言葉で決める

会食と贈答は分かりやすいですが、社内の飲み会、従業員への祝い、展示会での名刺交換の後の食事、取引先を訪ねるときの手土産を含めるかどうかで数字は大きく変わります。機械に任せる前に、含めるものと含めないものをこちらから指定します。おすすめは、社外の相手に向けた会食・贈答・ゴルフや催し・慶弔・手土産の五つをまず一覧にし、社内向けは別の欄に置くことです。混ぜると、取引先との付き合いの費用と、社内の福利の費用の区別がつかなくなります。

原則2：相手と用件は「記録にある内容」で書かせ、推測で埋めさせない

相手の名前がない領収書を、機械は店の場所や日付から「おそらくA社との会食だろう」と埋めたがります。記録にない相手と用件は空欄のまま残させ、推測で埋めさせません。推測で埋めた一覧は、見た目が整う分だけ、相手を書かずに使っている費用の多さを見逃します。空欄は、次に確かめる相手を教えてくれる印です。

原則3：一覧の合計と、帳簿の接待交際費を突き合わせる

一覧に並んだ費用の合計が、帳簿の接待交際費の年間の合計と合っているかを突き合わせさせます。合計が帳簿より小さい場合、一覧に入っていない付き合いがあります。たいていは、会議費として処理された少額の会食か、社長の立て替えで精算が遅れた分です。逆に一覧の方が大きい場合は、帳簿に載っていない社長の財布からの支出が混ざっています。差額の出どころを探すことが、記録の穴を見つける近道になります。

つまずきやすい5つの型

型1：合計の金額だけ見て、相手ごとの内訳を見ない

接待交際費の合計が増えたとき、全部の付き合いを一律に減らしがちですが、増えたのが特定の相手への会食なのか、贈答の単価なのか、相手の数なのかで打つ手は違います。相手ごと、種類ごとに分けて見ます。相手の数が増えたなら付き合う先の見直し、単価が増えたなら贈り物や店の選び方の見直しです。

型2：取引の大きさの違う相手どうしを比べる

年間の売上が数千万円の得意先と、まだ取引の始まっていない見込み先を、付き合いの費用の額だけで比べても、意味のある差は出ません。取引の大きさに対する割合で比べるか、同じ段階の相手どうしで比べます。段階を分けずに全部を一列に並べると、費用の多い相手と少ない相手が分かるだけで、次の手が決まりません。

型3：注文の有無だけで、付き合いの価値を決める

注文につながらなかった付き合いをすべて無駄とすると、金融機関や地域の団体、困ったときに助けてくれる同業者との関係まで削ってしまいます。種類と相手の性質ごとに、何をもって続ける理由とするかを先に決めます。得意先なら注文の動き、仕入先なら納期や条件の融通、金融機関や団体なら関係を保つこと自体、という具合です。

型4：義理で続けている贈答を、誰も見直さずに毎年発注する

お中元とお歳暮の送り先の一覧は、毎年前年の一覧をそのまま使って発注されがちです。発注の前に、送り先ごとの一年の取引の動きを並べ、注文の途絶えた相手と、新たに加えるべき相手に印をつけさせます。やめるかどうかは人が決めますが、一覧を見てから決めるのと、前年の一覧のまま送るのとでは、翌年の数字が変わります。

型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱりA社との会食が多い」と納得して終わると、次の年も同じ回数だけ会食します。月に一度、精算のときの用件の欄か、贈答の前に一覧を見る決まりか、一つでよいので決まりを変えます。変えた決まりが、次の月の数字の根拠になります。

業種別の効きどころ

業種効きどころ
建設・リフォーム元請や設計事務所ごとの会食と贈答の費用を、その先からの一年の受注額と並べ、紹介が続いている先と途絶えた先を分ける
製造・加工得意先の購買担当との付き合いの費用と、その得意先の受注の増減や条件の変化を並べる。仕入先への付き合いは納期や価格の融通と並べて別に見る
卸・商社取引先の数が多いため、付き合いの費用がその先の粗利の何割かで並べ替え、割合の重い先と、伸びているのに費用ゼロの先を見つける
士業・コンサル紹介元ごとの会食や贈答の費用と、その紹介元から来た一年の顧客数と報酬を並べ、紹介の続いている先を確かめる
飲食・小売取引先よりも、地域の団体や近隣の店との付き合いが中心になるため、費用を種類ごとに分け、催しや寄付の費用と来店の動きを並べる

どの業種でも共通するのは、帳簿の接待交際費の一行にまとまって消えていた付き合いの費用を、相手ごとの費用と取引の動きという二つの物差しで並べ直すことです。並べ直すと、続けるべき付き合いと、回数を減らせる付き合いと、これから費用を使うべき相手が分かれて見えてきます。

よくあるご質問

接待や贈り物は年に数えるほどしかありませんが、必要ですか

年に数回でも、一年分を並べると同じ相手への会食や毎年の贈答がまとまって見えてきます。回数が少ないうちに精算の欄を一行足し、月に一度の確認の決まりをつくっておく方が、取引先が増えたときに楽です。最初の一覧は半日で終わります。

領収書に相手の名前を書いておらず、誰との会食か分かりません

会社カードの明細や社内の予定表に日付と店の名前があれば、そこから相手を組み上げられる場合が多くあります。予定表の同じ日の来客や訪問と突き合わせれば、多くの会食は相手まで分かります。過去は分かる範囲で並べ、これからは精算のときに相手と用件を書く決まりを決めて残す、で十分です。

付き合いを減らすと、取引先との関係が悪くならないか心配です

一覧は減らすための道具ではなく、どの付き合いが関係を保つために必要かを見えるようにするための道具です。関係を保つための付き合いは種類として分けて残し、物差しも別にします。見直す候補は、相手の書かれていない費用や、一年間注文のない相手への贈答から見ていきます。減らして浮いた分を、これから伸ばしたい相手に回すという使い方もあります。

どれくらいの時間がかかりますか

一年分の領収書と明細を渡して最初の一覧が出るまでは、件数にもよりますが一時間ほどです。相手先ごとのまとめ直しと帳簿との突き合わせに数日、そのあとは月に一度、その月の付き合いを足して相手先ごとの累計と印を出させて確かめるだけです。

  • どの相手との付き合いを続けるか、贈り物をやめるか、義理をどこまで守るかは人の判断。集めて、相手先ごとにそろえて、費用と取引の動きに分けて並べるのは機械の仕事
  • 実務は、一年分の洗い出し、相手先ごとのまとめ直しと種類づけ、相手先ごとの合計を取引の大きさと並べる、取引の動きと並べて続ける付き合いと見直す付き合いを分ける、精算に欄を足して月に一度確かめる、の五つ
  • 付き合いの費用に何を含めるかをこちらから指定し、相手と用件は記録にある内容で書かせ、帳簿の接待交際費と突き合わせる
