2026.05.02 ─ Claude Code / Anthropic

Claude Code v2.1.126 リリース、OAuth・PowerShell 強化と claude project purge 新コマンド追加 ▼

5/1 リリースの Claude Code v2.1.126 では、WSL2/SSH/コンテナ環境で localhost にコールバックできない場合でもターミナル貼り付けコードで OAuth ログインできるよう改善。Bedrock/Vertex/Foundry など互換ゲートウェイのモデル検出も `/v1/models` 経由で精度向上。新コマンド `claude project purge` でプロジェクトのトランスクリプト/タスク/ファイル履歴/設定を一括削除可能に。さらに Windows では PowerShell 7 が複数インストール方法に対応し、Bash より優先される設計になった。一方で v2.1.63〜2.1.84 を対象に Git worktree を悪用した重大脆弱性 CVE-2026-40068 が報告されており、最新版への即時更新が推奨されている。

2026.05.02 ─ ChatGPT / OpenAI

ChatGPT Workspace Agents 発表、寝ている間に業務を進める常時稼働エージェントが Business 以上に展開 ▼

4/22 発表：OpenAI が ChatGPT に「Workspace agents」を追加。Business / Enterprise / Edu / Teachers プラン向けにプレビュー提供され、5/6 までは無料、その後はクレジット制で従量課金へ移行する。寝ている間にエージェントが資料整備・データ整理・調査を進める常時稼働型として注目を集めており、Anthropic の Cowork、Manus Cloud Computer、Replit Agent など同種の「24時間稼働 AI 同僚」が一斉に揃った形に。中小企業の単純業務オペレーションを夜間に AI で巻き取る運用が現実的になっている。

2026.05.02 ─ Gemini / Google

Google Cloud Next '26 で Gemini Enterprise 中心の発表、AI エージェント構築プラットフォームを統合 ▼

4/22〜24 開催の Google Cloud Next '26 では、AI エージェント構築プラットフォーム「Gemini Enterprise」が発表の中心となった。Gemini Enterprise Agent Platform を土台に、Gemini Enterprise App、Gemini Enterprise for Customer Experience が積層する構成で、旧称 Google Agentspace と Gemini Enterprise を統合・進化させた。料金体系も「Free + Pay-as-you-go」に統一され、従来のサブスクから従量課金へ全面移行。さらに 2026年7月まで日本/インドネシア/英国/ブラジルの18歳以上学生に Gemini 無料アップグレードを提供するなど、エンタープライズと若年層の両端を取りに行く戦略が鮮明化している。

2026.05.02 ─ ChatGPT / OpenAI

ChatGPT Images 2.0 公開、新アーキテクチャ gpt-image-2 で日本語テキスト描画と図解精度が大幅向上 ▼

4/21 公開の ChatGPT Images 2.0 は、新アーキテクチャ gpt-image-2 を採用し、ChatGPT/Codex/API の全ユーザーに即時提供。画像内の日本語テキスト描画能力が大幅向上し、生成過程で必要に応じて Web 検索を実行することで、図解・地図など正確性が要求されるビジュアルを直接出力できる。Codex への統合と相まって、ゲーム素材・販促物量産・LP インフォグラフィックといったクリエイティブ業務の AI 完結度が一段と進行している。

2026.05.02 ─ Claude Code / Anthropic

Anthropic 評価額 $350B に到達、Google 最大 $40B 投資コミットと NEC 協業で日本展開も加速 ▼

4/24 に Google が Anthropic（評価額 $350B）に対し最大 $40B の投資コミット（即時 $10B、業績条件で追加 $30B）を発表。Anthropic のランレート売上は 2025年末の約 $9B から $30B 超へ急増し、Amazon からも追加 $5B 投資、約 5GW のコンピュート確保で最大 $100B 規模の支出計画が並走する。日本では 4/24 に NEC との協業で AI エンジニア育成が始動、4/27 にはシドニー拠点が開設されオセアニア展開も加速。一方、米国防総省の AI 契約 7 社からは軍事用途のガードレール論争で除外され、サプライチェーンリスクとも分類されるなど、安全性方針を巡る摩擦も鮮明化している。

2026.05.02 ─ 業界全体の動向

AI 巨額投資と「人間の証明」需要が並走、24 時間稼働エージェントが業務 UI のデファクトに ▼

2026年4〜5月の AI 業界は、(1) Google→Anthropic $40B、Amazon→Anthropic 追加 $5B など計算インフラ獲得競争の激化、(2) OpenAI/Anthropic/Google による中国モデル複製対策での協調、(3) 米国防総省の AI 契約 7 社契約 (Anthropic は除外) と、地政学・資金・規制が同時に動く局面に。一方で Spotify が「人間アーティスト認証バッジ」を導入するなど、AI 生成と人間制作の識別需要が拡大。OpenAI Workspace agents、Manus Cloud Computer、Anthropic Cowork など 24 時間稼働エージェントが一気に揃い、中小企業でも夜間自動運転・常時稼働 AI 部署運用が現実解になりつつある。

Piste AI EVANGELISTS 代表 / AIコンサルタント / フィットネスクラブ経営者

岐阜大学工学部修士課程修了後、大手鉄鋼メーカー（愛知製鋼）にてエンジニアとして約8年間勤務。その後独立し、AIエンジニア・コンサルタントとして活動を開始。これまでに70社以上のAI導入コンサルティング実績があります。

現在はフィットネスクラブを経営しながら、パーソナルトレーナーとして月間100名の顧客を担当。予約管理・顧客対応・会計処理・SNS運用・集客施策など、あらゆる業務をAIで自動化し、一人で運営しています。

大手メーカーでの実務経験 × AIエンジニアの技術力 × 自らビジネスをAIで運営する実践知。「技術を知っている」だけでなく「実際にビジネスで使っている」現場目線で、お客様一人ひとりに寄り添ったレクチャーを得意としています。

2児の父。限られた時間で最大の成果を出すためにAI活用を徹底しています。
