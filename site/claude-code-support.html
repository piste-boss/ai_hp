Claude Code とは

Claude Code は、Anthropic 社が提供するAIコーディングツールです。プログラミングのためのツールとして生まれましたが、文章で指示を出すだけでファイルの整理、表の集計、文書の下書き、業務ツールとの連携まで任せられるため、非エンジニアの業務自動化ツールとして中小企業で使われ始めています。

ただし、インストールと認証、最初の指示の出し方、そして「どこまで触ってよいか」の安全な設定でつまずく方がとても多いのが実情です。Piste AI EVANGELISTS の導入サポートは、この最初の壁をマンツーマンで越えるためのサービスです。

導入サポートの内容（¥10,000 税込 / 1時間）

  • お使いのPC（Mac / Windows）への Claude Code のインストールと認証
  • 最初の指示の出し方と、結果の確認のしかた
  • 業務で使うための安全な設定（触ってよいフォルダ・やってはいけない操作の指定）
  • ご自身の業務に当てはめた「最初の1つの自動化」の相談

よくあるご質問

Q. プログラミングの経験がなくても受けられますか
A. はい。Claude Code は文章で指示を出すツールで、当社のサポートは非エンジニアの方を前提にしています。PCの基本操作ができれば問題ありません。
Q. オンラインで受けられますか
A. はい。Zoom を使った画面共有でのレクチャーが基本です。愛知県内の企業様は訪問についてもご相談ください。
Q. 1時間で何ができるようになりますか
A. Claude Code のインストールと認証、最初の指示の出し方、業務で使うときの安全な設定（触ってよい範囲の指定）までを一緒に進め、ご自身のPCで動く状態にします。具体的な業務への組み込みは継続プランで伴走します。
Q. 法人でなく個人事業主でも申し込めますか
A. はい。中小企業・個人事業主・フリーランスの方に幅広くご利用いただいています。
