## 1. Claude Code とは何か

Claude Code は、Anthropic が公式に提供している AI コーディングツールです。名前に「コーディング」とありますが、できることはプログラム作成だけではありません。手元の資料や売上データを読み取り、内容を理解し、文章にまとめ、決まった手順を何度でも繰り返し実行してくれます。

操作は日本語の会話だけで完結します。「この商品の説明文を、写真の見栄えに合う短い言葉で3案つくって」と伝えるだけで作業が進みます。関数もプログラムも覚える必要がないため、日々パソコンやタブレットを触っている方であれば十分に使いこなせます。

デリバリー運用は「文章をつくる」「数字を数える」「同じ作業を繰り返す」の集まりです。まさに Claude Code の得意分野が重なる領域といえます。

## 2. デリバリーの注文が伸びない本当の理由

料理の味に問題がなくても、宅配で選ばれないことはよくあります。原因の多くは、料理そのものではなく「見せ方」と「振り返り」にあります。

- 商品名だけが並び、どんな味なのかが伝わっていない
- 写真は良いのに、添える言葉が「おいしい」だけで差が出ていない
- セットや組み合わせの提案がなく、注文単価が上がらない
- 時間帯や曜日ごとの売れ方を把握しないまま、同じ品揃えを続けている
- 悪い評価が付いても、なぜそう感じられたのかを振り返れていない

画面の中で他店と横並びになる以上、伝わる言葉があるかどうかで結果が変わります。しかし営業中の店主に、文章を練る時間はほとんどありません。

## 3. デリバリー運用で自動化できる5つの活用シーン

### 1. メニュー説明文づくり

「使っている素材」「調理法」「どんなときに食べてほしいか」を伝えると、宅配向けの説明文をいくつも提案してくれます。宅配は届くまでに時間が空くため、店内とは違う訴求が要ります。「冷めてもおいしい」「持ち帰りやすい容器」といった宅配ならではの安心材料を、自然な言葉で盛り込めます。

### 2. 商品写真に添える短い言葉づくり

一覧画面で目に入るのは、写真と数十文字の言葉だけです。「一言で食欲をそそる表現を5案」と頼めば、長さを揃えた候補が並びます。その中から店の雰囲気に合うものを選ぶだけで、全商品の言葉が短時間で整います。

### 3. セット商品・販促企画のたたき台づくり

「平日の昼にひとりで注文する方向けのセットを考えて」と伝えれば、組み合わせと価格帯の案が出てきます。単品ばかりで注文単価が伸び悩む店にとって、この提案づくりだけでも効果があります。

### 4. 評価コメントへの返信文づくり

寄せられた感想に返す言葉も任せられます。厳しい内容ほど返信の書き方に悩むものですが、事実を受け止めつつ改善の姿勢を示す文面のたたき台があれば、感情的にならずに済みます。公開前に必ず店主が読み、自店の言葉に整えてから使います。

### 5. 売上データの集計と月次の振り返り

管理画面から取り出した注文データを渡し、「時間帯別・商品別に集計して、伸びている商品と落ちている商品を挙げて」と指示すれば、表と要点がまとまって出てきます。感覚ではなく数字で品揃えを見直せるようになり、翌月の打ち手が具体的になります。

## 5. 導入の4ステップ

1. **改善したい商品を5つに絞る**：全品を一度に見直そうとせず、売りたい商品や伸ばしたい商品から手を付けます。効果が見えやすく、続けやすくなります。
2. **材料をそろえる**：使っている素材、調理のこだわり、想定する食べる場面をメモにまとめます。この材料の濃さが、出てくる文章の質をそのまま決めます。
3. **Claude Code に日本語で指示する**：「この商品の説明文を、宅配で選ばれる視点で3案つくって」と伝えます。出てきた案に「もっと短く」「素材の名前を前に」と注文を重ねて仕上げます。
4. **小さく試して広げる**：まず数品だけ差し替え、2週間ほど注文の動きを見ます。手応えがあれば同じやり方を他の商品にも広げていきます。

| 売上の振り返り | 感覚で判断している | 時間帯別・商品別の数字を根拠に判断できる |

## 7. 運用上の注意点

- **公開前は必ず人が確認する**：味や量に関わる表現は、実物と食い違うと信頼を損ないます。最終確認は必ず店主が行います。
- **誇大な表現は避ける**：「日本一」「絶対に」といった断定は避け、素材や調理法など事実で伝えます。
- **注文者の個人情報は扱わない**：氏名や住所を含むデータは渡さず、集計に必要な商品名と数量だけを使います。
- **自店らしさを残す**：整った文章ほど無個性になりがちです。最後に店主の言葉をひとこと足すだけで印象が変わります。
- **管理画面の権限は最小限に**：外部とつなぐ場合は、必要な範囲だけを許可します。最初から全体を開放する必要はありません。

## よくある質問

**パソコンが得意ではありませんが使えますか。**

日本語で「こうしたい」と伝えるだけで進められます。専門的な知識は要りません。

**書いてもらった文章をそのまま使ってよいですか。**

たたき台として受け取り、店主が確認して整えてから使ってください。実物との食い違いを防ぐためにも、最終判断は人が担います。

**複数の宅配サービスに出店していますが対応できますか。**

できます。サービスごとに文字数や見え方が違うため、「短い版」「詳しい版」を用意しておくと使い回しが楽になります。

**何から始めるのがよいですか。**

いちばん売りたい商品1つの説明文づくりから始めてください。仕上がりを見れば、次に任せたい作業が自然に見えてきます。
