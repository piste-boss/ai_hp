## 1. Wantedlyの採用でつまずきがちな3つの壁

Wantedlyは、給与や条件よりも「会社の想いやカルチャーへの共感」を軸に候補者と出会える採用サービスです。魅力を伝える発信が成果を左右する一方で、次のような壁にぶつかりがちです。

- **募集記事・ストーリー記事づくりが重い**：会社の想いや仕事の魅力を文章にする作業は時間がかかり、後回しになりがちです。
- **発信を続けられない**：一度つくって終わりになり、更新が止まって候補者の関心が離れてしまいます。
- **候補者対応に時間が取れない**：スカウト文やカジュアル面談の準備を一人でこなすのは負担が大きいものです。

これらは「発信力が足りない」からではなく、言語化と継続にかかる手間が原因です。ここはまさにAIが得意とする領域です。

## 2. Claude CodeでWantedly運用のどこを自動化できるのか

Claude Codeは、会社の情報や過去の投稿を読み込ませることで、自然言語の指示だけで次のような作業を手伝ってくれます。

- **募集記事の下書き作成**：仕事内容や求める人物像を伝えると、共感を呼ぶ募集文のたたき台を複数案で提案します。
- **ストーリー記事のネタ出しと構成**：社員紹介・創業の想い・働く環境など、発信テーマの候補と記事の骨組みを用意します。
- **スカウト文の下書き**：候補者の経歴に合わせた、丁寧で温度のあるスカウト文の下書きをつくります。
- **カジュアル面談の準備**：聞くべき質問や自社の伝えどころを整理し、面談の進め方のたたき台を用意します。
- **反響データの整理**：閲覧数やエントリーの傾向をまとめ、次に何を発信すべきかのヒントを示します。

いずれも「AIがたたき台を高速でつくり、人が仕上げて発信を判断する」という役割分担が基本です。

## 3. 業種別・採用広報の活用シーン

### IT・Web制作会社
技術や社風の魅力を、専門外の候補者にも伝わる言葉に整えられます。エンジニア募集の記事づくりを効率化できます。

### 飲食店・小売・サービス業
現場の雰囲気や働きがいを、写真の説明文とあわせて魅力的に発信できます。アルバイトから正社員まで幅広い募集に対応します。

### 建設・製造・地域の中小企業
知名度が高くなくても、仕事の社会的な意義や技術力をストーリーで伝えることで、共感してくれる候補者と出会いやすくなります。

### 士業・コンサル・専門事務所
少人数だからこその働き方や成長環境を言語化し、価値観の合う人材へ届く発信を続けられます。

### スタートアップ・一人社長の事業
創業の想いやビジョンを軸に、共感採用ならではの発信を無理なく継続できます。

## 4. 導入の4ステップ

専門的なプログラミングは不要です。次の4ステップで無理なく始められます。

### ステップ1：目的を1つに絞る
「募集記事を量産したい」「ストーリー発信を続けたい」「スカウト文を効率化したい」など、困りごとを1つに絞ります。

### ステップ2：材料の準備
仕事内容・求める人物像・社風・働く環境・過去の投稿などを、日本語でまとめておきます。材料が多いほど自社らしい文章になります。

### ステップ3：Claude Codeへの業務指示
「この職種で募集記事を3案」「この社員の紹介記事の構成を」といった具体的な指示を日本語で伝え、出力を見ながら自社のトーンに調整します。

### ステップ4：小さく試して広げる
まずは1本から試し、閲覧数や反響を確かめてから発信の幅を広げます。公開前の最終確認は必ず人が行います。

## 5. 運用で押さえておきたい注意点

- **公開前の確認は人が行う**：AIはあくまで下書き役です。事実関係やトーンの最終確認は人が行います。
- **誇大な表現を避ける**：働く環境や待遇について、実態と異なる表現にならないよう必ず見直します。
- **自社らしさを守る**：AIの文章は整いすぎて無個性になりがちです。自分たちの言葉で温度を加えます。
- **候補者情報は丁寧に扱う**：応募者の経歴や個人の情報は、社内で慎重に取り扱います。
- **認証情報は最小権限で管理する**：採用サービスの操作権限は、必要な範囲に絞って安全に管理します。

AIはあくまで「採用活動を続けるための手伝い役」です。会社の想いや人を大切にする姿勢は、人が持ち続けることが大切です。
