# Claude Codeで有給休暇の取得記録を整える！中小企業のための従業員別の取得一覧づくりと取り残しと偏りを見つける判断材料整理ガイド

**2026年9月22日 ・ 読了目安 約9分**

「あの人、今年は有給を何日使ったんだっけ」「年に五日は取らせないといけないと聞いたが、誰が足りていないのか分からない」「いつも同じ人ばかり休んでいる気がする」。中小企業では、有給休暇の申請が紙の届け出や口頭のひと言、カレンダーの書き込みで済まされ、誰が何日使い、何日残っているかを一覧で見たことがある会社はほとんどありません。入社日ごとに付与される日数も時期も違い、前の年からの繰り越しがあり、半日の取得や時間単位の取得が混ざり、帳簿にも給与明細にも「有給」の一行はあっても、その中身は担当者の記憶と、机の引き出しの届け出の束にしか残っていません。

その結果、何が起きるか。年度の終わりに「五日に足りない人がいる」と気づいて、あわてて三月に休ませる。同じ人が毎月きちんと使い、別の人はまったく使っておらず、その差が本人の性格の問題にされて終わる。退職の申し出があって初めて残日数を数え、最後の一か月がまるごと消化に充てられて現場が回らなくなる。**有給休暇の本当の問題は、休みが多いか少ないかではなく、誰に何日残っていて、誰が取り残していて、誰に偏っているかを並べて見たことがないため、早めに調整する手が打てないことです**。

この記事では、Anthropic社の公式AIコーディングツール **Claude Code** を使って、届け出、勤怠の記録、給与明細の控え、カレンダーに散らばった有給休暇の記録を従業員ごと年度ごとの一覧にそろえ、付与日数と取得日数と残日数を並べ、取り残しと偏りを見つける材料を整えるまでの手順を、非エンジニアの方向けに整理します。誰にいつ休んでもらうか、繁忙期をどう避けるか、取りにくい空気をどう変えるかを決めるのは人の判断。機械に任せるのは、**散らばった記録を集めて、従業員と年度でそろえて、付与と取得と残りに分けて並べる作業**です。

## 有給休暇が「見えない」3つの理由

見えないのは、総務の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

### 1. 付与の日と日数が、人によって全部違う

有給休暇は入社から半年で最初の日数が付与され、その後は一年ごとに増えていきます。**入社日が違えば付与の日も違い、勤続年数が違えば付与の日数も違い、週の勤務日数が少ない人はさらに別の日数になります**。全員が四月に一斉に同じ日数というわけではないため、会社全体を一つの表で見ようとすると、人ごとに基準日が違う表になります。この違いが、一覧をつくる前に手を止めさせます。

### 2. 「取った記録」が三か所に分かれ、形がそろっていない

有給の取得は、紙の届け出、勤怠の打刻や出勤簿、給与計算のときの控えの三か所に残ります。**紙は日付だけ、出勤簿は「有」の印だけ、給与の控えは月の合計日数だけで、三つを突き合わせないと一人の一年分が組み上がりません**。半日の取得が紙には「半」と書かれ、出勤簿には出勤扱いで、給与の控えでは零点五日になっていることも珍しくありません。

### 3. 残日数の「当たり前の幅」を誰も知らない

年度の途中で残りが何日あるかを、本人も会社も知らないまま進みます。**残りが十日ある人と一日しかない人が同じ職場にいて、その差がいつから広がったのかを数字で知っている会社はほとんどありません**。残りの幅が分かっていないと、取り残しと偏りを分けられず、年度末に「使い切れないので買い取ってほしい」「今月は全員休みが重なって現場が回らない」という形で表に出ます。

> 有給休暇が見えないのは、付与の基準日が人ごとに違い、取得の記録が三か所に分かれ、残日数の幅を誰も知らないからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

大前提として、**誰にいつ休んでもらうか、繁忙期をどう避けるか、休みにくい空気をどう変えるか、残日数の扱いをどうするかは会社の運営の判断**であり、人が決めることです。機械に任せるのは、散らばった記録を集めて従業員と年度でそろえ、付与と取得と残りを横に並べ、比べられる形にするところまでです。

## 実務5ステップ

### ステップ1：過去二年分の届け出と出勤簿を洗い出す

紙の届け出、出勤簿か勤怠の記録、給与計算の控え、社内のカレンダーを二年分集め、Claude Codeに「この二年の有給休暇を従業員ごと年度ごとの一覧にし、付与・取得・残りを並べてほしい」と頼みます。一年分では繰り越しの計算ができないため、**二年分が最初の単位**です。届け出が見つからない日は、**空欄のまま残させます**。出勤簿には印があるのに届け出がない日は、口頭で済ませた日です。空欄そのものが、記録の流れのどこが抜けているかを教えてくれます。

### ステップ2：氏名と年度をそろえる

同じ人が「山田」「山田さん」「山田太郎」のように三通りで書かれていたり、部署の異動で別の出勤簿に移っていたりします。**呼び名を一人にまとめ、入社日から人ごとの付与の基準日を出し、その基準日から一年を一つの年度としてそろえます**。あわせて、正社員・パート・週の勤務日数の区分をつけます。区分が違えば付与される日数が違うため、区分をつけずに並べると、多い少ないに意味がなくなります。

### ステップ3：残日数を出し、取り残しを「見込み」で見る

一覧を人ごと年度ごとにまとめ、付与と繰り越しの合計から取得を引いて残日数を出します。**年度の何割が過ぎたかと、五日のうち何日を取ったかを並べ、このままの進み方で年度末までに五日に届かない人を出します**。この見込みが、有給を見る物差しになります。年度末に足りないと気づいてからでは、繁忙期に休ませるしかありません。年度の半分が過ぎた時点で一日も取っていない人は、残りの半年で五日を組む必要があると分かります。同じ「まだ取っていない」でも、年度の始めと終わりでは打つ手がまったく違います。

### ステップ4：偏りを出し、人の問題と仕組みの問題を分ける

月ごと部署ごとに取得日数を並べ、全体の平均の半分に届かない人と、取得が特定の月に集まっている部署を出します。**特定の人だけが取れていないなら、その人の担当している仕事に代わりがいないという仕組みの問題**であることがほとんどです。部署全体が取れていないなら、その部署の人数か繁忙期の組み方の問題です。逆に、残日数が二年分の上限に近づいている人は、次の付与で消えてしまう日数を抱えています。ここで初めて、「経理の担当者だけ二年間で三日しか取っていない」「工場は毎年八月に全員が集中して、七月と九月は誰も取っていない」という形が見えます。

### ステップ5：届け出の置き場を決め、月に一度だけ確かめる

一覧ができたら、届け出を一つの箱か一つの表に必ず入れる、あるいは勤怠の記録に「有給」の欄を一つ足すという一つの決まりだけつくります。**月に一度、その月の取得を反映させ、残日数と年度末までの見込みを人ごとに出させ、五日に届かない見込みの人と偏っている部署を出させます**。細かい運用にすると続きません。一か月に一度、十五分で終わる形にします。

## 頼み方の3原則

### 原則1：「有給」に何を含めるかを、こちらから言葉で決める

法律で決まった年次の有給休暇は分かりやすいですが、会社が独自に設けている夏季休暇や誕生日の休み、時間単位の取得、半日の取得、私傷病の欠勤を有給に振り替えた日を含めるかどうかで数字は変わります。機械に任せる前に、**含めるものと含めないものをこちらから指定します**。おすすめは、法律の年次有給休暇だけをまず一覧にし、会社独自の休みは別の欄に置くことです。混ぜると、五日の義務に届いているかが見えなくなります。

### 原則2：取得日は「届け出か出勤簿にある日付」で書かせ、推測で埋めさせない

給与の控えに月三日とあって届け出が二枚しかない月を、機械は「もう一日はどこかの平日だろう」と埋めたがります。**記録にない日付は空欄のまま残させ、推測で埋めさせません**。推測で埋めた一覧は、月ごとの偏りが整って見える分だけ、口頭で済ませている日の多さを見逃します。空欄は、次に確かめる相手を教えてくれる印です。

### 原則3：一覧の合計と、給与の控えの有給日数を突き合わせる

一覧に並んだ取得日数の合計が、給与計算の控えにある有給の日数の合計と合っているかを突き合わせさせます。**合計が給与の控えより小さい場合、届け出のない取得があります**。たいていは、口頭で済ませた半日か、退職者の消化分です。差額の出どころを探すことが、記録の穴を見つける近道になります。

## つまずきやすい5つの型

### 型1：取得日数だけ見て、付与日数と年度の経過を見ない

年に三日しか取っていない人を「取れていない人」と決めがちですが、入社したばかりで付与がまだ十日に満たない人なら三日は十分です。**付与日数と年度の経過と取得日数の三つを並べて見ます**。付与が多いのに取得が少ない人と、付与そのものが少ない人は、責める相手も打つ手も違います。

### 型2：区分の違う人どうしを比べる

週五日の正社員と週三日のパートを取得日数で比べても、意味のある差は出ません。**同じ区分の人どうし、あるいは同じ人の去年と今年で比べます**。区分をつけずに全員を一列に並べると、多い人と少ない人が分かるだけで、次の手が決まりません。

### 型3：半日と時間単位を、全日と同じ一日に置く

半日の取得を一日と数えると、残日数が実際より少なく出て、年度末に「まだ残っていた」となります。**半日は零点五日、時間単位は所定の時間で割った日数にそろえ、全日と同じ単位で並べます**。そろえ直しは地味ですが、飛ばすと残日数も五日の判定も全部ずれます。

### 型4：取れていない理由を、全部「本人の性格」にする

休まない人を「真面目だから」で済ませると、その人の仕事に代わりがいないという仕組みの問題に気づけません。**取れていない人の担当している仕事と、その仕事を他に誰ができるかを並べます**。本人の性格の中に、仕組みの穴が隠れています。

### 型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱり経理が取れていない」と納得して終わると、次の年度も同じ人が取り残します。月に一度、届け出の置き場か、月初に休みの予定を尋ねる決まりか、一つでよいので決まりを変えます。変えた決まりが、次の月の数字の根拠になります。

## 業種別の効きどころ

| 業種 | 効きどころ |
|---|---|
| 製造・加工 | 工程ごとに取得の月を並べ、盆と年末に集中して他の月が空いている工程を見つける。交代で取る順番を組む材料にし、一人しかできない工程の担当者の取り残しを早めに見つける |
| 建設・リフォーム | 現場ごとの工期と取得日を並べ、工期の谷に休みを寄せられている職長とそうでない職長を分ける。現場の掛け持ちが多い人ほど残日数が積み上がる形を見つける |
| 飲食・小売 | 店舗ごと曜日ごとの取得を並べ、特定の店だけ誰も休めていない月を見つける。店長の残日数と応援に入れる人の有無を並べ、応援の組み方の材料にする |
| 介護・医療 | 夜勤の回数と取得日数を並べ、夜勤が多い人ほど取れていない形を見つける。シフトを組む前に残日数と見込みを出し、五日に届かない人を先に組み込む |
| 士業・サービス | 担当している顧客の数と取得日数を並べ、担当が多い人ほど取れていない形を見つける。繁忙期の前後に休みの予定を先に尋ねる材料にする |

どの業種でも共通するのは、**引き出しの届け出の束と出勤簿の印でしか残っていなかった有給休暇を、人ごとの付与と取得と残りという三つの物差しで並べ直すこと**です。並べ直すと、本人に声をかければ済む分と、仕事の代わりを用意しないと減らない分と、繁忙期の組み方を変えないと直らない分が分かれて見えてきます。

## よくあるご質問

### 従業員が数人でも必要ですか

数人でも、人ごとに付与の基準日が違い、繰り越しがあり、半日の取得が混ざれば、頭の中では追い切れません。人数が少ないうちに届け出の置き場と月に一度の確認の決まりをつくっておく方が、人が増えたときに楽です。最初の一覧は半日で終わります。

### 届け出を紙で残しておらず、口頭で済ませてきました

出勤簿や勤怠の記録に休みの印があれば、まずそこから日付を拾います。給与の控えに月ごとの有給日数があれば、それを合計の当たりにします。過去は日付が分かる分だけ並べ、分からない分は月の合計だけを置き、これからは届け出の置き場を決めて日付を残す、で十分です。

### 残日数を本人に見せてもよいのでしょうか

本人の残日数を本人に伝えることは、取り残しを減らすうえでいちばん効きます。年度の途中で残日数と年度末までの見込みを添えて休みの予定を尋ねる文面は、機械に下書きさせられます。他の人の残日数は本人以外に見せない形にし、部署の偏りは日数の合計だけで扱います。

### どれくらいの時間がかかりますか

二年分の届け出と出勤簿を渡して最初の一覧が出るまでは、人数にもよりますが一時間ほどです。氏名と年度のそろえ直しと給与の控えとの突き合わせに数日、そのあとは月に一度、その月の取得を反映させて残日数と見込みを出させて確かめるだけです。

- 誰にいつ休んでもらうか、繁忙期をどう避けるか、休みにくさをどう変えるかは人の判断。集めて、そろえて、付与と取得と残りに分けて並べるのは機械の仕事
- 実務は、二年分の洗い出し、氏名と年度のそろえ直し、残日数と年度末までの見込みを出す、人の問題と仕組みの問題を分ける、届け出の置き場を決めて月に一度確かめる、の五つ
- 有給に何を含めるかをこちらから指定し、取得日は届け出か出勤簿にある日付で書かせ、給与の控えの有給日数と突き合わせる
