# Claude Codeで出張の費用と目的の記録を整える！中小企業のための出張ごとの費用一覧づくりと続ける出張・減らす出張を分ける判断材料整理ガイド

**2026年9月23日 ・ 読了目安 約9分**

「今月は出張が多かった気がするが、全部でいくらかかったのか分からない」「あの展示会、毎年行っているけれど何か残っているのか」「同じ取引先に、なぜ毎月二人で行っているのか」。中小企業では、出張の費用が新幹線や飛行機の領収書、ホテルの予約の控え、ガソリン代と高速代の立て替え精算、日当の支給記録に分かれ、帳簿では「旅費交通費」の一行にまとまって消えていきます。一回の出張にいくらかかり、何のために行き、何が持ち帰られたのかを一覧で見たことがある会社はほとんどありません。

その結果、何が起きるか。決算のときに旅費交通費が去年より大きく増えていることに気づいても、どの出張が増やしたのか説明できない。毎年の恒例になった展示会や本社訪問が、成果を確かめられないまま続いていく。逆に、行けば受注につながっていた現地調査が「経費削減」の一言でまとめて減らされる。**出張の本当の問題は、費用が高いか安いかではなく、一回ごとの費用と目的と持ち帰ったものを並べて見たことがないため、続ける出張と減らす出張を分けられないことです**。

この記事では、Anthropic社の公式AIコーディングツール **Claude Code** を使って、領収書、予約の控え、精算書、日当の記録、社内の予定表に散らばった出張の記録を一回ごとの一覧にそろえ、費用と目的と結果を並べ、続ける出張と減らす出張を見分ける材料を整えるまでの手順を、非エンジニアの方向けに整理します。どの出張を続けるか、誰が行くか、画面越しの打ち合わせに切り替えるかを決めるのは人の判断。機械に任せるのは、**散らばった記録を集めて、出張一回ごとにそろえて、費用と目的と結果に分けて並べる作業**です。

## 出張が「見えない」3つの理由

見えないのは、経理の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

### 1. 一回の出張の費用が、四つの書類に分かれる

一回の出張で、交通の領収書、宿泊の領収書、車で行けばガソリン代と高速代と駐車場代、そして日当の支給記録が別々に出てきます。**支払った人も、支払った日も、精算した月も違うため、一回の出張がいくらだったかは、四つを突き合わせないと組み上がりません**。会社のカードで払った分と個人が立て替えた分が混ざると、同じ出張が二つの精算に分かれて月をまたぐことも珍しくありません。

### 2. 「何のために行ったか」が、どこにも書かれていない

精算書には行き先と金額は書かれていても、目的の欄は「打ち合わせ」「営業」の一言か空欄です。**目的が書かれていなければ、行った結果として何が持ち帰られたか、つまり受注につながったのか、問題が片付いたのか、情報を集めただけなのかを、後から確かめる手がかりがありません**。行った本人の記憶の中にしか残っていない情報が、会社の判断材料になっていないのです。

### 3. 「行くかどうか」の基準がなく、前例で決まる

去年も行ったから今年も行く、先方に呼ばれたから行く、二人で行くのが慣例だから二人で行く。**出張の多くは、費用と成果を比べたうえではなく、前例と相手との関係で決まっています**。基準がないため、増えても減っても理由が説明できず、減らすときには一律に何割という形になりがちです。

> 出張が見えないのは、一回の費用が四つの書類に分かれ、目的と結果がどこにも書かれず、行くかどうかの基準が前例で決まっているからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

## 機械に任せる範囲と、人が決める範囲

大前提として、**どの出張を続けるか、誰が行くか、何人で行くか、画面越しの打ち合わせに切り替えるか、取引先との関係をどう保つかは会社の運営の判断**であり、人が決めることです。機械に任せるのは、散らばった記録を集めて出張一回ごとにそろえ、費用と目的と結果を横に並べ、比べられる形にするところまでです。

| 工程 | 担当 | 内容 |
|---|---|---|
| 記録の収集 | 機械 | 交通と宿泊の領収書・予約の控え・立て替え精算書・会社カードの明細・日当の支給記録・社内の予定表から、日付・行き先・人・金額・用件の記載を拾い出す |
| 出張一回ごとのまとめ直し | 機械 | 日付と行き先と人が重なる記録を一回の出張としてまとめ、月をまたいだ精算や二人分に分かれた精算を一つにそろえる |
| 一覧化 | 機械 | 出張日・行き先・取引先・人数・交通費・宿泊費・車の費用・日当・合計・目的・結果を一行にそろえる |
| 目的の種類づけ | 機械 | 商談・現地調査・納品や施工の立ち会い・展示会・研修・社内の拠点訪問の六つ前後の種類に分ける |
| 費用の集計 | 機械 | 取引先ごと、目的の種類ごと、人ごとに、一年間の回数と合計と一回あたりの費用を出す |
| 結果の突き合わせ | 機械 | 出張の後三か月以内に同じ取引先から見積もりの依頼や受注があったかを、受注の記録と並べて印をつける |
| 偏りの検出 | 機械 | 一回あたりの費用が同じ種類の平均より三割以上高い出張、同じ取引先に毎月行っている出張、結果の印が一年間一度もつかない出張に印をつける |
| 見直し案の下書き | 機械 | 印のついた出張について、回数を減らす・人数を減らす・画面越しに切り替える・続けるの四つの案と、それぞれの費用の差を並べる |
| 続けるか減らすかの判断 | 人 | どの出張を続けるか、誰が行くか、取引先との関係をどう保つかを決める |

境界線は「並べる」と「決める」の間にあります。機械が出すのは、出張一回ごとの費用と目的と結果の並びと、偏りの印までです。その先の、関係を保つために行き続けるか、回数を減らすかの線は、人が引きます。

## 実務5ステップ

### ステップ1：過去一年分の出張の記録を洗い出す

交通と宿泊の領収書、予約の控え、立て替え精算書、会社カードの明細、日当の支給記録、社内の予定表を一年分集め、Claude Codeに「この一年の出張を一回ごとの一覧にし、費用と目的を並べてほしい」と頼みます。展示会や繁忙期の偏りがあるため、**一年分が最初の単位**です。目的が書かれていない出張は、**空欄のまま残させます**。空欄そのものが、記録の流れのどこが抜けているかを教えてくれます。

### ステップ2：出張一回ごとにまとめ、目的の種類をつける

同じ出張が、新幹線は会社のカード、ホテルは個人の立て替え、日当は翌月の給与と、三つの月に分かれて記録されています。**日付と行き先と人が重なる記録を一回の出張としてまとめ、合計を出します**。あわせて、商談・現地調査・立ち会い・展示会・研修・拠点訪問のように目的の種類をつけます。種類が違えば一回あたりの費用の当たり前も違うため、種類をつけずに並べると、高い安いに意味がなくなります。

### ステップ3：一回あたりの費用と、取引先ごとの年間の合計を出す

一覧を目的の種類ごと、取引先ごとにまとめ、一年間の回数と合計と一回あたりの費用を出します。**同じ取引先への出張が年に何回あり、合わせていくらかかっているかが、出張を見る物差しになります**。一回の費用が安くても毎月行けば大きな額になり、一回の費用が高くても年に一度なら小さな額です。回数と一回あたりを分けて見ると、減らすなら回数なのか、行き方なのかが見えてきます。

### ステップ4：結果と並べ、続ける出張と見直す出張を分ける

受注の記録や見積もりの依頼の記録を横に置き、出張の後三か月以内に同じ取引先から動きがあったかに印をつけます。**印がつく出張は続ける候補、一年間一度も印がつかない出張は見直す候補です**。ただし、既存の取引先を保つための訪問や、施工の立ち会いのように行かなければ仕事が進まない出張は、受注の印がつかなくても必要です。ここで初めて、「A社には毎月二人で行っているが、この一年で見積もりの依頼は一度もない」「現地調査に行った案件は、行かなかった案件の倍の割合で受注している」という形が見えます。

### ステップ5：精算書に目的と結果の欄を一行足し、月に一度だけ確かめる

一覧ができたら、精算書に「目的の種類」と「持ち帰ったもの」の欄を一行ずつ足すという一つの決まりだけつくります。**月に一度、その月の出張を一覧に足させ、取引先ごとの合計と印のついた出張を出させます**。細かい報告書にすると続きません。一か月に一度、十五分で終わる形にします。

## 頼み方の3原則

### 原則1：「出張」に何を含めるかを、こちらから言葉で決める

泊まりがけの遠方出張は分かりやすいですが、日帰りの近隣訪問、社用車での移動、展示会の出展費用、手土産や会食の費用を含めるかどうかで数字は大きく変わります。機械に任せる前に、**含めるものと含めないものをこちらから指定します**。おすすめは、交通・宿泊・車の費用・日当の四つをまず一覧にし、手土産や会食は別の欄に置くことです。混ぜると、行き方の費用と付き合いの費用の区別がつかなくなります。

### 原則2：金額と目的は「記録にある内容」で書かせ、推測で埋めさせない

目的の欄が空欄の出張を、機械は行き先から「おそらく商談だろう」と埋めたがります。**記録にない目的は空欄のまま残させ、推測で埋めさせません**。推測で埋めた一覧は、見た目が整う分だけ、目的を書かずに出張している回数の多さを見逃します。空欄は、次に確かめる相手を教えてくれる印です。

### 原則3：一覧の合計と、帳簿の旅費交通費を突き合わせる

一覧に並んだ出張の合計が、帳簿の旅費交通費の年間の合計と合っているかを突き合わせさせます。**合計が帳簿より小さい場合、一覧に入っていない出張があります**。たいていは、月をまたいだ立て替え精算か、会社カードの明細にしか残っていない分です。差額の出どころを探すことが、記録の穴を見つける近道になります。

## つまずきやすい5つの型

### 型1：合計の金額だけ見て、回数と一回あたりを見ない

旅費交通費の合計が増えたとき、全部の出張を一律に減らしがちですが、増えたのが回数なのか一回あたりの費用なのかで打つ手は違います。**回数と一回あたりを分けて見ます**。回数が増えたなら行く理由の見直し、一回あたりが増えたなら行き方や泊まり方の見直しです。

### 型2：目的の違う出張どうしを比べる

一泊二日の展示会と日帰りの現地調査を一回あたりの費用で比べても、意味のある差は出ません。**同じ目的の種類どうし、あるいは同じ取引先への去年と今年で比べます**。種類をつけずに全部を一列に並べると、高い出張と安い出張が分かるだけで、次の手が決まりません。

### 型3：受注の印だけで、出張の価値を決める

受注につながらなかった出張をすべて無駄とすると、既存の取引先との関係を保つ訪問や、問題を早く片付けるための立ち会いまで削ってしまいます。**目的の種類ごとに、何を持ち帰れば成果とするかを先に決めます**。商談なら見積もりの依頼、立ち会いなら手直しの有無、展示会なら名刺の枚数ではなくその後の商談の件数、という具合です。

### 型4：一人で行けるか、画面越しで済むかを考えずに前例で決める

二人で行くのが慣例、毎月行くのが慣例という出張は、慣例のまま続いていきます。**印のついた出張ごとに、一人で行った場合と、三回に一回を画面越しにした場合の費用の差を並べます**。差額が見えると、慣例を変えるかどうかを話し合う材料になります。

### 型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱりA社への訪問が多い」と納得して終わると、次の年も同じ回数だけ行きます。月に一度、精算書の欄か、出張前に目的の種類を書く決まりか、一つでよいので決まりを変えます。変えた決まりが、次の月の数字の根拠になります。

## 業種別の効きどころ

| 業種 | 効きどころ |
|---|---|
| 建設・リフォーム | 現地調査に行った案件と行かなかった案件の受注の割合を並べ、行く価値の高い調査を見分ける。遠方の現場の立ち会いの回数と手直しの件数を並べる |
| 製造・加工 | 取引先の工場への訪問の回数と、その後の追加注文や仕様の確定を並べる。立ち会いが多い取引先と、図面のやりとりで済んでいる取引先を分ける |
| 卸・商社 | 取引先ごとの年間の訪問費用と、その取引先の年間の粗利を並べ、訪問費用が粗利に対して重すぎる取引先を見つける |
| 士業・コンサル | 顧客ごとの訪問の回数と費用を並べ、画面越しの打ち合わせに切り替えても支障のない顧客と、現地で見る必要のある顧客を分ける |
| 飲食・小売の多店舗 | 本部から各店舗への巡回の回数と費用を並べ、巡回の多い店と売上や手直しの指摘の件数を並べて巡回の順番を組み直す材料にする |

どの業種でも共通するのは、**帳簿の旅費交通費の一行にまとまって消えていた出張を、一回ごとの費用と目的と結果という三つの物差しで並べ直すこと**です。並べ直すと、続けるべき出張と、回数を減らせる出張と、行き方を変えれば安くなる出張が分かれて見えてきます。

## よくあるご質問

### 出張は月に数回しかありませんが、必要ですか

月に数回でも、一年分を並べると同じ取引先への訪問や恒例の展示会がまとまって見えてきます。回数が少ないうちに精算書の欄を一行足し、月に一度の確認の決まりをつくっておく方が、出張が増えたときに楽です。最初の一覧は半日で終わります。

### 領収書を捨ててしまい、会社カードの明細しかありません

明細に日付と金額と支払先があれば、そこから一回の出張を組み上げられます。宿泊先や交通の支払先から行き先を拾い、社内の予定表と突き合わせれば、多くの出張は目的まで分かります。過去は分かる範囲で並べ、これからは精算書の欄を決めて残す、で十分です。

### 出張を減らすと、取引先との関係が悪くならないか心配です

一覧は減らすための道具ではなく、どの出張が関係を保つために必要かを見えるようにするための道具です。関係を保つ訪問は目的の種類として分けて残し、成果の物差しも別にします。減らす候補は、目的の書かれていない出張や、同じ用件で二人が行っている出張から見ていきます。

### どれくらいの時間がかかりますか

一年分の領収書と精算書を渡して最初の一覧が出るまでは、件数にもよりますが一時間ほどです。出張一回ごとのまとめ直しと帳簿との突き合わせに数日、そのあとは月に一度、その月の出張を足して取引先ごとの合計と印を出させて確かめるだけです。

## まとめ

- 出張が見えないのは、一回の費用が四つの書類に分かれ、目的と結果がどこにも書かれず、行くかどうかの基準が前例で決まっているという構造の問題
- どの出張を続けるか、誰が行くか、画面越しに切り替えるかは人の判断。集めて、一回ごとにそろえて、費用と目的と結果に分けて並べるのは機械の仕事
- 実務は、一年分の洗い出し、一回ごとのまとめ直しと目的の種類づけ、一回あたりと取引先ごとの合計を出す、結果と並べて続ける出張と見直す出張を分ける、精算書に欄を足して月に一度確かめる、の五つ
- 出張に何を含めるかをこちらから指定し、目的は記録にある内容で書かせ、帳簿の旅費交通費と突き合わせる
- 回数と一回あたりを分けて見る。目的の違う出張は比べない。成果の物差しは目的の種類ごとに決め、慣例は費用の差を並べて見直し、月に一度、決まりを一つ変える
