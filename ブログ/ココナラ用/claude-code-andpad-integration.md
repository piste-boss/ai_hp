この記事では、Anthropic公式のAIコーディングツール Claude Code と施工管理アプリ ANDPAD（アンドパッド）の運用を組み合わせ、工事日報づくり・現場写真の整理・工程変更の案内文・案件データの集計までを、パソコンが苦手な方にも分かる言葉で解説します。

## Claude Code とは何か

Claude Code は、Anthropic が公式に提供しているAIコーディングツールです。名前に「コーディング」と付いていますが、できることはプログラムづくりだけではありません。手元の資料やデータを読み取り、内容を理解し、文章にまとめ、決まった手順を何度でも繰り返してくれます。

操作は日本語の会話だけで完結します。「この現場メモから今日の日報を書いて」と伝えるだけで作業が進みます。専門用語も関数も覚える必要がないため、普段スマートフォンやパソコンで書類を扱っている方であれば十分に使えます。

施工管理の事務作業は「文章をつくる」「写真や書類を並べ替える」「同じ作業を毎日繰り返す」の集まりです。まさに Claude Code の得意分野と重なる領域といえます。

## 建設・リフォーム会社の事務作業が終わらない理由

現場の腕に問題がなくても、事務作業だけが積み上がっていく会社は少なくありません。原因は段取りではなく「書く作業の総量」にあります。

- 日報・作業報告を現場ごとに毎日書かなければならない
- 現場写真が撮影順のまま並び、どの工程のものか後から分からなくなる
- 工程が1日動くと、関係先ごとに文面を変えて案内し直すことになる
- 追加工事の説明を口頭で済ませ、後から認識の食い違いが出る
- 案件ごとの利益や工期の実績を集計できず、次の見積りに活かせない

ANDPAD のような施工管理アプリを入れると情報は1か所に集まりますが、集まった情報を「読む人に伝わる文章」に変える作業は依然として人の手に残ります。ここが Claude Code の入りどころです。

## ANDPAD運用で自動化できる5つの活用シーン

### 1. 工事日報・作業報告の下書きづくり

現場で打ち込んだ短いメモや音声を書き起こしたものを渡し、「これを日報の体裁に整えて」と伝えるだけで下書きが出てきます。「本日の作業」「進捗率」「翌日の予定」「気付いた点」といった項目立てをあらかじめ決めておけば、毎日同じ形式でそろいます。現場から戻ってから書き始めるのではなく、確認して直すだけで終わります。

### 2. 現場写真の整理と説明文づくり

管理アプリに上げた写真は、後から探すときに苦労しがちです。撮影日と工程の対応表を渡し、「基礎・上棟・内装・完了の工程ごとに分けて、それぞれ一言の説明を付けて」と頼めば、並べ替えの案と説明文がまとまって出てきます。施主への報告資料づくりにも、そのまま使えます。

### 3. 工程変更・進捗案内の文面づくり

天候や資材の都合で工程が動くのは日常のことです。「明後日の外壁作業が2日後ろにずれる。施主向け・協力会社向け・社内向けの3種類の案内文をつくって」と伝えれば、相手ごとに言葉の硬さを変えた文面が並びます。伝え漏れが減り、書き直す時間もなくなります。

### 4. 追加工事・見積り内容の説明文づくり

追加工事は、金額の話より「なぜ必要なのか」の説明で納得が決まります。工事内容と理由を箇条書きで渡し、「専門用語を使わずに施主へ説明する文章にして」と頼むと、分かりやすい説明文が出てきます。書面で残せば、後の認識の食い違いも防げます。

### 5. 案件データの集計と月次の振り返り

管理アプリから書き出した案件データを渡し、「工種別・現場別に工期と原価を集計して、予定と実績の差が大きい現場を挙げて」と指示すれば、表と要点がまとまって出てきます。感覚ではなく数字で振り返れるようになり、次の見積りの精度が上がります。

## 導入の4ステップ

1. **自動化する作業を1つに絞る**：まずは日報の下書きだけ、と決めます。全部を一度に変えようとすると続きません。
2. **材料をそろえる**：現場メモの取り方、日報の項目、案内文の言い回しを1か所にまとめます。この材料の濃さが、出てくる文章の質をそのまま決めます。
3. **Claude Code に日本語で指示する**：「このメモから日報を書いて」と伝えます。出てきた文章に「もっと短く」「専門用語を減らして」と注文を重ねて自社の形に近づけます。
4. **小さく試して広げる**：1現場で2週間ほど続け、手応えを確かめてから他の現場に広げます。

## 運用上の注意点

- **施主に出す前は必ず人が確認する**：工期や金額に関わる記載は、実際の内容と食い違うと信頼を損ないます。最終確認は必ず担当者が行います。
- **図面や個人情報の扱う範囲を決める**：氏名や住所を含む書類は渡さず、集計に必要な項目だけを使います。社内で扱う範囲を先に決めておくと安心です。
- **安全や法令に関わる判断は任せない**：確認申請や検査に関わる判断は人が行います。AIは文章づくりと集計の担当と割り切ります。
- **管理アプリの権限は必要最小限に**：外部とつなぐ場合は、必要な範囲だけを許可します。最初から全体を開放する必要はありません。
- **自社らしさを残す**：整った文章ほど無個性になりがちです。最後に担当者のひとことを足すだけで印象が変わります。

## よくある質問

**パソコンが得意ではありませんが使えますか。**

日本語で「こうしたい」と伝えるだけで進められます。専門的な知識は要りません。

**施工管理アプリを入れていなくても使えますか。**

使えます。手元の写真やメモ、表計算ソフトの案件表があれば、そこから日報や集計をつくれます。アプリを入れている場合は、書き出したデータを渡すことでさらに手間が減ります。

**現場の職人にも使ってもらえますか。**

まずは事務担当や現場監督が使い、出てきた文章を共有する形が現実的です。効果が見えてから使う範囲を広げるほうが定着します。

**何から始めるのがよいですか。**

いちばん手間を感じている作業から始めてください。多くの会社では日報の下書きづくりが最初の一歩になります。
