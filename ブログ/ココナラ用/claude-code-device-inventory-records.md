# Claude Codeで会社のパソコンとスマホの台帳を整える！中小企業のための端末ごとの利用者と購入時期の一覧づくりと買い替える端末・使い続ける端末を分ける判断材料整理ガイド

**2026年9月28日 ・ 読了目安 約9分**

「会社のパソコンが全部で何台あるのか、すぐには答えられない」「辞めた人が使っていたスマホが、いまどこにあるのか分からない」「動きが遅いと言われるたびに、その場で一台ずつ買い足している」。中小企業では、会社のパソコンやスマホの記録が、購入したときの納品書と請求書、家電量販店や通販の購入履歴、携帯の契約の明細、リースの契約書、固定資産の台帳、そして使っている本人の机の上に分かれ、帳簿では「消耗品費」「通信費」「リース料」「工具器具備品」に散らばって消えていきます。どの端末を誰が使っていて、いつ買って、あと何年使えるのかを一覧で見たことがある会社は、ほとんどありません。

その結果、何が起きるか。五年以上前のパソコンが、仕事の遅さの原因になっていることに気づかない。反対に、まだ十分使える端末が、入れ替えのたびに引き出しの奥で眠っている。退職した人の端末が回収されないまま、会社の書類が入った状態で残っている。**端末の本当の問題は、台数が多いか少ないかではなく、端末ごとの利用者と購入時期を一枚に並べたことがないため、買い替える端末と使い続ける端末を分けられないことです**。

この記事では、Anthropic社の公式AIコーディングツール **Claude Code** を使って、納品書、購入履歴、携帯の契約の明細、リースの契約書、固定資産の台帳に散らばった端末の記録を一つの一覧にそろえ、端末ごとの利用者と購入時期と費用を並べ、買い替える端末と使い続ける端末を見分ける材料を整えるまでの手順を、非エンジニアの方向けに整理します。どの端末を買い替えるか、誰にどの端末を渡すか、どこまでの費用をかけるかを決めるのは人の判断です。機械に任せるのは、**散らばった記録を集めて、端末ごとにそろえて、利用者と購入時期と費用に分けて並べる作業**です。

## 端末の中身が「見えない」3つの理由

見えないのは、総務の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

### 1. 一台の端末の記録が、買い方ごとに別々の場所に残る

パソコンは量販店で、スマホは携帯会社の店頭で、複合機のそばのパソコンはリースで、急ぎの一台は通販でと、**会社の端末は、必要になったときに、その時々の買い方で増えていきます**。納品書は経理の箱に、購入履歴は担当者の通販の画面に、携帯の契約は毎月の明細に、リースは契約書のつづりにと、置き場所も分かれています。全部を一度に机に並べた人が、社内に一人もいないのです。

### 2. 帳簿では端末が「一台」ではなく「金額」でしか残らない

十万円を超えるパソコンは固定資産の台帳に載りますが、それより安いものは消耗品費として一行で消えます。スマホの本体代は通信費の分割払いに混ざり、リースの端末はリース料の中に入ります。**同じ「パソコン一台」が、買い方によって三つも四つもの科目に分かれる**ため、帳簿を見ても何台あるのかは分かりません。

### 3. 買い替えのきっかけが「壊れた」「遅い」という声しかない

端末を見直すのは、壊れたときか、使っている人から遅いと言われたときだけ、という会社がほとんどです。**しかも声の大きい人の端末から入れ替わるため、会社全体の端末を一度に見直す機会がありません**。その間に、人が増えた、辞めた、担当が変わった、という会社の変化があっても、端末の記録はそのまま残ります。

> 端末の中身が見えないのは、買い方ごとに記録の場所が分かれ、帳簿では金額でしか残らず、買い替えのきっかけが壊れたときの声しかないからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

## 機械に任せる範囲と、人が決める範囲

大前提として、**どの端末を買い替えるか、誰にどの端末を渡すか、どこまでの費用をかけるか、使わなくなった端末をどう処分するかは会社の運営の判断**であり、人が決めることです。機械に任せるのは、散らばった記録を集めて端末ごとにそろえ、利用者と購入時期と費用を横に並べ、比べられる形にするところまでです。

| 工程 | 担当 | 内容 |
|---|---|---|
| 記録の収集 | 機械 | 納品書・請求書・購入履歴・携帯の契約の明細・リースの契約書・固定資産の台帳から、機種・製造番号・購入日・購入先・金額・契約の期間を拾い出す |
| 端末ごとのまとめ直し | 機械 | 同じ端末の納品書と台帳と契約の明細を、製造番号や回線の番号を手がかりに一台の下にまとめる |
| 一覧化 | 機械 | 端末の種類・機種・製造番号・購入日・買い方・金額・今の利用者・置き場所を一行にそろえる |
| 使用年数の計算 | 機械 | 購入日から今日までの年数と、リースや分割払いの残りの期間を出す |
| 費用の集計 | 機械 | 端末ごと、利用者ごと、部署ごとに、本体代と毎月の契約の費用を一年分にならした額を出す |
| 人の名簿との突き合わせ | 機械 | 従業員の名簿と、今の利用者の欄を並べる |
| 偏りと抜けの検出 | 機械 | 使用年数が五年を超えた端末、利用者が空欄の端末、退職した人の名前が残っている端末、一人で二台以上持っている人、端末のない人に印をつける |
| 見直し案の下書き | 機械 | 印のついた端末について、買い替え・回し使い・回収・処分の候補と理由を並べる |
| 端末の判断 | 人 | どの端末を買い替えるか、誰にどの端末を渡すか、回収した端末をどう扱うか、次の買い方をそろえるかを決める |

境界線は「並べる」と「決める」の間にあります。機械が出すのは、端末ごとの利用者と購入時期と費用の並びと、偏りと抜けの印までです。その先の、この人の仕事にはこの性能が要るか、この端末はあと一年使うか、という線は人が引きます。

## 実務5ステップ

### ステップ1：会社にある端末の記録を全部洗い出す

直近五年分の納品書と請求書、通販の購入履歴、携帯の契約の明細、リースの契約書、固定資産の台帳を集め、Claude Codeに「会社にあるパソコンとスマホを一覧にし、利用者と購入日と費用を並べてほしい」と頼みます。**帳簿と契約の明細から先に拾うのが近道です**。納品書が見つからない端末も、買ったときのお金の出どころは必ず帳簿か明細に残っています。利用者が分からない端末は、**空欄のまま残させます**。その空欄が、現物を確かめに行く端末を教えてくれます。

### ステップ2：端末ごとにまとめ、種類と買い方をつける

同じ端末が、納品書では機種名、台帳では資産番号、契約の明細では回線の番号と、三つの書き方で記録されています。**製造番号や回線の番号を手がかりに三つを結びつけ、一台の中身と費用を一行にまとめます**。あわせて、事務用パソコン、持ち歩き用パソコン、スマホ、タブレットのように種類をつけ、買い取り、分割払い、リースのように買い方をつけます。買い方を分けずに並べると、本当の一台あたりの費用が比べられません。

### ステップ3：今の利用者を、人の名簿と並べる

一覧ができたら、従業員の名簿を横に置きます。**会社にいる一人ひとりについて、どの端末を使っているかを並べるのが、端末を見る物差しになります**。端末の側から見ると抜けは見えませんが、人の側から見ると、端末のない人、二台持っている人、もういない人の名前が残った端末がはっきりします。一覧の利用者の欄は、実際に机を回って確かめた結果で直します。

### ステップ4：偏りと抜けに印をつけ、見直す候補を分ける

使用年数が五年を超えた端末、利用者が空欄の端末、退職した人の名前が残っている端末、一人で二台以上持っている人に印をつけます。**印がついたものは、すぐに買い替える・回収するのではなく、見直す候補として理由を添えて一覧にします**。ここで初めて、「営業の二人は六年目のパソコンで見積もりをつくっている」「辞めた人のスマホが二台、契約だけ続いている」という形が見えます。

### ステップ5：入れ替えの決まりを一つつくり、三か月に一度だけ確かめる

一覧ができたら、端末を買った・渡した・回収したら一覧の行を直す、という一つの決まりだけつくります。**三か月に一度、次の三か月に使用年数の目安を超える端末と、この間に入った人と辞めた人を並べさせます**。細かい報告書にすると続きません。三か月に一度、十五分で終わる形にします。人が入る、辞める、担当が変わる、というときは、その場で一覧に一行足させ、どの端末を渡すか、どの端末を回収するかを確かめます。

## 頼み方の3原則

### 原則1：「端末」に何を含めるかを、こちらから言葉で決める

パソコンとスマホだけを見るか、タブレット、複合機のそばの共用パソコン、店頭のレジの端末、社員が自分のスマホを仕事に使っている分まで含めるかで、一覧の形は大きく変わります。機械に任せる前に、**含めるものと含めないものをこちらから指定します**。おすすめは、一人ひとりが使う端末と、みんなで使う共用の端末を、まず別々の一覧にすることです。混ぜると、一人あたりの台数の話と、共用の端末の古さの話が一緒になり、どちらも判断しにくくなります。

### 原則2：購入日と利用者は「記録にある内容」で書かせ、推測で埋めさせない

機種名だけを見て、機械は「おそらくこの年に買ったものだろう」と埋めたがります。**納品書や台帳で確かめられない購入日は空欄のまま残させ、推測で埋めさせません**。利用者も同じです。推測で埋めた一覧は、見た目が整う分だけ、本当は所在の分からない端末を見逃します。空欄は、次に現物を確かめに行く端末を教えてくれる印です。

### 原則3：一覧の費用の合計と、帳簿の科目を突き合わせる

一覧に並んだ端末の費用の合計が、帳簿の消耗品費、通信費、リース料、工具器具備品のうち端末に関わる分と合っているかを突き合わせさせます。**合計が帳簿より小さい場合、一覧に入っていない端末があります**。たいていは、社長が個人の支払いで買った端末、通信費に混ざった本体の分割代、使っていないのに続いている契約の分です。差額の出どころを探すことが、忘れられた端末を見つける近道になります。

## つまずきやすい5つの型

### 型1：古い順に全部を買い替えようとする

使用年数の長い端末から一気に入れ替えがちですが、事務の入力にしか使わない端末と、見積もりや図面を扱う端末では、求められる性能が違います。**使用年数は、使っている人の仕事と並べて見ます**。古くても仕事に足りている端末を回し使いに回すのか、新しくても足りていない端末を入れ替えるのかで、打つ手は正反対です。

### 型2：買い方が違うだけで、費用を比べられないと思い込む

買い取り、分割払い、リースと買い方が違っても、一年あたりにならせば並べて比べられます。反対に、月々の支払いが安く見えても、期間が長いと割高なこともあります。**買い方ではなく、一年あたりの費用と使える年数の二つで並べ直します**。並べ直すと、次に買うときの買い方の目安が見えてきます。

### 型3：人の出入りを、端末の一覧に反映しない

人が入った、辞めた、担当が変わった、という変化があっても、端末の一覧はそのまま、ということがよくあります。**人の出入りのたびに一覧を直す、という決まりをつくります**。反映しないまま一年たつと、辞めた人の端末にかかり続ける契約の費用と、所在の分からない端末が、同時に積み上がります。

### 型4：回収した端末を、そのまま引き出しにしまう

入れ替えで回収した端末は、まだ使えるものと、中の書類を消して処分するものに分けないと、引き出しの奥で眠り続けます。**回収した端末も一覧に残し、回し使い・処分待ちの印をつけます**。処分の方法や中の書類の消し方は人が決めますが、一覧に残してから決めるのと、しまい込んで忘れるのとでは、翌年の台数が変わります。

### 型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱり古い端末が多い」と納得して終わると、次も壊れた順の入れ替えが続きます。三か月に一度、見直す候補を一つ選び、使っている人に困りごとを聞いて、結果を一覧に書き足します。書き足した結果が、次の買い替えの判断の根拠になります。

## よくあるご質問

### パソコンは数台しかありませんが、必要ですか

台数が少なくても、人の側から並べると、使用年数の長い端末や契約だけ続いているスマホが見えてくることがあります。台数が少ないうちに一覧の形をつくっておく方が、人が増えたときに楽です。最初の一覧は半日で終わります。

### 購入したときの書類が残っていない端末があります

帳簿と契約の明細から、買った月と金額までは分かることがほとんどです。機種と製造番号は、端末の裏のシールや設定の画面で確かめられます。分からない端末は、一覧に空欄のまま残し、現物を確かめる端末の一覧として使います。

### 買い替えの判断まで機械に任せてよいですか

機械に任せるのは、並べることと、偏りと抜けの印をつけることまでです。どの端末を買い替えるか、誰に渡すかは、仕事の中身や予算で答えが変わるため、人が決めます。一覧があると、使っている人との話し合いが短く、具体的になります。

### どれくらいの時間がかかりますか

帳簿と契約の明細と台帳を渡して最初の一覧が出るまでは、台数にもよりますが一時間ほどです。人の名簿との突き合わせと現物の確認に数日、そのあとは三か月に一度、使用年数の目安を超える端末と人の出入りを並べさせて確かめるだけです。
