# Claude Codeで保険の加入状況を整える！中小企業のための保険ごとの補償と保険料の一覧づくりと重なる補償・足りない補償を分ける判断材料整理ガイド

**2026年9月27日 ・ 読了目安 約9分**

「会社で入っている保険が全部でいくつあるのか、すぐには答えられない」「工場の火災保険と、機械のリースについている保険と、どこまで同じものを守っているのか分からない」「保険料は毎年払っているが、何かあったときに本当に出るのか確かめたことがない」。中小企業では、会社が入っている保険の記録が、保険証券の束、更新のたびに届く案内の書類、口座の引き落としの明細、代理店の担当者の手帳、リースや借入の契約書の付帯の条項に分かれ、帳簿では「保険料」の一行にまとまって消えていきます。どの保険が何を、いくらまで守っていて、一年でいくら払っているのかを一覧で見たことがある会社は、ほとんどありません。

その結果、何が起きるか。建物の火災保険と、設備の保険と、リース物件の保険で同じ機械を二重、三重に守っていることに気づかない。反対に、仕事の途中でお客様の物を壊したときの賠償や、工場が止まっている間の売上の穴は、どの保険でも守られていないことに、何かが起きてから気づく。更新の案内が来るたびに、前年と同じ内容でそのまま続けている。**保険の本当の問題は、保険料が高いか安いかではなく、保険ごとの補償の中身を一枚に並べたことがないため、重なっている補償と足りない補償を分けられないことです**。

この記事では、Anthropic社の公式AIコーディングツール **Claude Code** を使って、保険証券、更新の案内、引き落としの明細、帳簿に散らばった保険の記録を一つの一覧にそろえ、守っている物と出来事ごとに補償を並べ、重なる補償と足りない補償を見分ける材料を整えるまでの手順を、非エンジニアの方向けに整理します。どの保険を続けるか、どこまでの損を会社で抱えるか、補償を足すか減らすかを決めるのは人の判断です。専門的な確認は、保険の担当者や専門家の力を借りて進めます。機械に任せるのは、**散らばった記録を集めて、保険ごとにそろえて、守っているものと保険料に分けて並べる作業**です。

## 保険の中身が「見えない」3つの理由

見えないのは、総務の担当者が記録をさぼっているからではありません。見えない構造が、仕事の側にあります。

### 1. 一つの会社の保険が、五つの書類と三つの窓口に分かれる

火災保険は建物を建てたときに、自動車保険は車を買ったときに、賠償の保険は取引先に求められたときに、経営者の保険は借入のときにと、**会社の保険は、必要になった時期も窓口もばらばらに入っています**。保険証券は金庫に、更新の案内は総務の引き出しに、リースの付帯保険は契約書の後ろのページにと、置き場所も分かれています。全部を一度に机に並べた人が、社内に一人もいないのです。

### 2. 保険証券は「何を守るか」ではなく「何を約束するか」で書かれている

保険証券には、保険の対象、保険金額、支払われない場合、特約の名前が、保険会社ごとの言葉で並んでいます。**同じ「設備の故障」でも、ある保険では対象に入り、別の保険では支払われない場合の欄に書かれている**、ということが珍しくありません。書き方がそろっていないため、二つの証券を横に並べても、どこが重なり、どこが抜けているかは一目では分かりません。

### 3. 見直しのきっかけが「更新の案内」しかない

保険の中身を考えるのは、年に一度の更新の案内が届いたときだけ、という会社がほとんどです。**しかも案内は保険ごとに別々の時期に届くため、会社全体の保険を一度に見直す機会がありません**。その間に、工場を増やした、車を減らした、新しい仕事を始めた、という会社の変化があっても、保険の中身はそのまま残ります。

> 保険の中身が見えないのは、五つの書類と三つの窓口に分かれ、証券の書き方がそろっておらず、見直しのきっかけが保険ごとの更新の案内しかないからです。この三つは、いずれも機械に任せて軽くできる種類の問題です。

## 機械に任せる範囲と、人が決める範囲

大前提として、**どの保険を続けるか、どこまでの損を会社で抱えるか、補償を足すか減らすか、どの保険会社や担当者と付き合うかは会社の運営の判断**であり、人が決めることです。補償の中身の最終的な確認は、保険の担当者や専門家と行います。機械に任せるのは、散らばった記録を集めて保険ごとにそろえ、守っている物と出来事ごとに横に並べ、比べられる形にするところまでです。

| 工程 | 担当 | 内容 |
|---|---|---|
| 記録の収集 | 機械 | 保険証券・更新の案内・引き落としの明細・リースや借入の契約書の付帯の条項・帳簿の保険料から、保険の名前・保険会社・対象・保険金額・期間・保険料を拾い出す |
| 保険ごとのまとめ直し | 機械 | 同じ保険の証券と案内と引き落としを、証券番号を手がかりに一つの保険の下にまとめる |
| 一覧化 | 機械 | 保険の名前・保険会社・守っている物・守っている出来事・保険金額・期間・年間の保険料・更新月を一行にそろえる |
| 守っているものの種類づけ | 機械 | 建物と設備・車両・お客様や第三者への賠償・仕事が止まったときの売上・人のけがや病気のように、五つ前後に分ける |
| 保険料の集計 | 機械 | 種類ごと、保険会社ごと、更新月ごとに、一年間の保険料の合計と会社全体に占める割合を出す |
| 会社の資産と仕事との突き合わせ | 機械 | 固定資産の台帳、車両の一覧、リースの一覧、取引先との契約の条件と、保険で守られている物を並べる |
| 重なりと抜けの検出 | 機械 | 同じ物や出来事を二つ以上の保険が守っているもの、台帳にあるのにどの保険にも出てこない物、取引先との契約で求められている補償が見当たらないもの、手放した物にかかり続けている保険に印をつける |
| 確認事項の下書き | 機械 | 印のついた項目について、保険の担当者に確かめる質問の下書きを、保険ごとに並べる |
| 補償の判断 | 人 | どの保険を続けるか、補償を足すか減らすか、どこまでの損を会社で抱えるか、更新の時期をそろえるかを決める |

境界線は「並べる」と「決める」の間にあります。機械が出すのは、守っているものごとの補償の並びと、重なりと抜けの印までです。その先の、この損は会社で抱えられるか、この補償は取引先との関係のために残すか、という線は人が引きます。

## 実務5ステップ

### ステップ1：会社が入っている保険の記録を全部洗い出す

保険証券、直近の更新の案内、一年分の引き落としの明細、帳簿の保険料の元帳、リースや借入の契約書を集め、Claude Codeに「会社が入っている保険を一覧にし、守っている物と出来事と保険料を並べてほしい」と頼みます。**引き落としの明細と帳簿から先に拾うのが近道です**。証券が見つからない保険も、毎月か毎年、お金が出ていれば必ず明細に残っています。証券と結びつかない引き落としは、**空欄のまま残させます**。その空欄が、証券を取り寄せる保険を教えてくれます。

### ステップ2：保険ごとにまとめ、守っているものの種類をつける

同じ保険が、証券では証券番号、案内では保険の名前、口座の明細では保険会社の略称と、三つの書き方で記録されています。**証券番号を手がかりに三つを結びつけ、一つの保険の中身と保険料を一行にまとめます**。あわせて、建物と設備、車両、賠償、仕事が止まったときの売上、人のけがや病気のように種類をつけます。一つの保険がいくつもの種類を守っている場合は、種類ごとに行を分けます。分けずに並べると、どの出来事が二重に守られているかが見えません。

### ステップ3：守られている物を、会社の資産と仕事と並べる

一覧ができたら、固定資産の台帳、車両の一覧、リースの一覧、主な取引先との契約の条件を横に置きます。**会社にある物とやっている仕事の一つひとつについて、どの保険が守っているかを並べるのが、補償を見る物差しになります**。保険の側から見ると抜けは見えませんが、会社の資産と仕事の側から見ると、どの保険にも出てこない物がはっきりします。

### ステップ4：重なりと抜けに印をつけ、確かめる項目を分ける

同じ物や出来事を二つ以上の保険が守っているもの、台帳にあるのにどの保険にも出てこない物、取引先との契約で求められている補償が見当たらないもの、手放した車や設備にかかり続けている保険に印をつけます。**印がついたものは、すぐにやめる・足すのではなく、保険の担当者に確かめる項目として一覧にします**。ここで初めて、「A工場の機械は、建物の保険とリースの保険の両方に入っている」「お客様の現場で物を壊したときの賠償は、どの保険にも見当たらない」という形が見えます。

### ステップ5：更新月を一覧に固定し、三か月に一度だけ確かめる

一覧ができたら、更新の案内が届いたら一覧の行を更新する、という一つの決まりだけつくります。**三か月に一度、次の三か月に更新を迎える保険と、この間に増えた物や減った物、始めた仕事を並べさせます**。細かい報告書にすると続きません。三か月に一度、十五分で終わる形にします。設備を買った、車を手放した、新しい取引先と契約した、というときは、その場で一覧に一行足させ、どの保険の範囲に入るかを確かめます。

## 頼み方の3原則

### 原則1：「保険」に何を含めるかを、こちらから言葉で決める

損害保険だけを見るか、経営者や従業員の生命保険、共済、リースの付帯の保険、取引先と一緒に入っている保険、クレジットカードについている補償まで含めるかで、一覧の形は大きく変わります。機械に任せる前に、**含めるものと含めないものをこちらから指定します**。おすすめは、会社の物と仕事を守る保険と、人を守る保険を、まず別々の一覧にすることです。混ぜると、物の補償の重なりと、人の保障の厚さの話が一緒になり、どちらも判断しにくくなります。

### 原則2：補償の中身は「証券にある内容」で書かせ、推測で埋めさせない

保険の名前だけを見て、機械は「おそらくこの出来事も守られているだろう」と埋めたがります。**証券や約款で確かめられない補償は空欄のまま残させ、推測で埋めさせません**。推測で埋めた一覧は、見た目が整う分だけ、本当は守られていない出来事を見逃します。空欄は、次に保険の担当者に確かめる項目を教えてくれる印です。

### 原則3：一覧の保険料の合計と、帳簿の保険料を突き合わせる

一覧に並んだ保険料の合計が、帳簿の保険料の年間の合計と合っているかを突き合わせさせます。**合計が帳簿より小さい場合、一覧に入っていない保険があります**。たいていは、リース料や借入の返済にまとめて払っている保険料、車両の費用に入っている保険料、社長が個人で払っている保険の分です。差額の出どころを探すことが、忘れられた保険を見つける近道になります。

## つまずきやすい5つの型

### 型1：保険料の合計だけ見て、補償の中身を見ない

保険料を下げたいとき、合計だけを見て高いものから削りがちですが、削った保険が守っていた出来事が、ほかのどの保険にも出てこないことがあります。**保険料は、守っているものの種類ごとに並べて見ます**。重なっている補償を減らすのか、抜けている補償を足すのかで、打つ手は正反対です。

### 型2：保険の名前が違うだけで、重なっていないと思い込む

火災の保険、動産の保険、機械の保険、リースの保険と名前が違っても、同じ機械を守っていることがあります。反対に、名前が似ていても守っている出来事が違うこともあります。**名前ではなく、守っている物と出来事の二つで並べ直します**。並べ直すと、名前だけでは見えなかった重なりが見えてきます。

### 型3：会社の変化を、保険の一覧に反映しない

工場を増やした、車を減らした、新しい仕事を始めた、取引先から補償を求められた、という変化があっても、保険の一覧はそのまま、ということがよくあります。**変化のたびに一覧に一行足す、という決まりをつくります**。反映しないまま一年たつと、手放した車にかかり続ける保険料と、新しい仕事の抜けた補償が、同時に積み上がります。

### 型4：更新の時期がばらばらで、全体を一度に見直せない

保険ごとに更新の月が違うと、一つずつ見直すたびに全体とのつり合いが分からなくなります。**更新月を一覧に並べ、次の三か月に来るものをまとめて確かめる形にします**。更新の時期をそろえるかどうかは人が決めますが、並べてから担当者と話すのと、案内が来るたびに前年どおりで続けるのとでは、翌年の中身が変わります。

### 型5：一覧をつくって、決まりを一つも変えない

一覧を眺めて「やっぱり重なっている保険がある」と納得して終わると、次の更新も前年どおりで続きます。三か月に一度、確かめる項目を一つ選び、保険の担当者に確かめて、結果を一覧に書き足します。書き足した結果が、次の更新の判断の根拠になります。

## 業種別の効きどころ

| 業種 | 効きどころ |
|---|---|
| 製造・加工 | 建物の保険と機械の保険とリースの保険を、固定資産の台帳の一台ずつと並べ、同じ機械の重なりと、工場が止まったときの売上の補償の有無を確かめる |
| 建設・改修 | お客様の現場で物を壊したときの賠償、預かった材料や道具の補償、下請けの方のけがの補償を、請け負う仕事の種類ごとに並べる |
| 飲食・小売 | 店舗ごとの建物と設備の保険、食中毒などお客様への賠償、停電や設備の故障で店を閉めたときの補償を並べ、店舗ごとの抜けを確かめる |
| 運送・配送 | 車両ごとの自動車保険と、運んでいる荷物の補償を並べ、車を入れ替えたときに外し忘れた保険と、荷物の種類に対して足りない補償を確かめる |
| 士業・サービス | 仕事の誤りでお客様に損を与えたときの賠償、預かった書類や情報の補償、事務所の設備の保険を並べ、取引先との契約で求められている補償と照らし合わせる |

どの業種でも共通するのは、**帳簿の保険料の一行にまとまって消えていた保険を、守っている物と守っている出来事という二つの物差しで並べ直すこと**です。並べ直すと、そのままでよい保険と、重なっている補償と、足りない補償が分かれて見えてきます。

## よくあるご質問

### 入っている保険は数本しかありませんが、必要ですか

本数が少なくても、会社の資産と仕事の側から並べると、どの保険にも出てこない物や出来事が見えてくることがあります。本数が少ないうちに一覧の形をつくっておく方が、会社が大きくなったときに楽です。最初の一覧は半日で終わります。

### 保険証券が見つからない保険があります

引き落としの明細と帳簿から、保険会社と保険料と引き落としの月までは分かります。証券は、保険会社や担当者に再発行を頼めば取り寄せられることがほとんどです。見つからない保険は、一覧に空欄のまま残し、取り寄せる保険の一覧として使います。

### 保険の良し悪しまで機械に判断させてよいですか

機械に任せるのは、並べることと、重なりと抜けの印をつけることまでです。どの保険がよいか、補償を足すか減らすかは、会社がどこまでの損を抱えられるかで答えが変わるため、人が決めます。専門的な中身は、保険の担当者や専門家と一緒に確かめます。一覧があると、その話し合いが短く、具体的になります。

### どれくらいの時間がかかりますか

保険証券と引き落としの明細と帳簿を渡して最初の一覧が出るまでは、本数にもよりますが一時間ほどです。会社の資産と仕事との突き合わせに数日、そのあとは三か月に一度、次に更新を迎える保険と会社の変化を並べさせて確かめるだけです。
