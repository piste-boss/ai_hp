1. Claude Code とは何か

Claude Code は、Anthropic が公式に提供している AI コーディングツールです。名前に「コーディング」とありますが、できることはプログラム作成だけではありません。パソコンの中にあるファイルを読み取り、内容を理解し、文章を書き、表にまとめ、決まった手順を繰り返し実行してくれます。

操作は日本語の会話だけで完結します。「この募集条件で募集文を3パターン作って」「先月の稼働データから曜日別に人手が足りない時間帯を出して」と伝えるだけで作業が進みます。専門知識がなくても扱えるため、店舗や倉庫の現場でパソコンを使う方であれば十分に活用できます。

2. スキマバイト活用でなぜ「現場の準備」が重荷になるのか

スキマバイトは、人手が足りない時間帯だけ働き手を確保できる仕組みです。募集のハードルは下がりましたが、そのぶん現場側では別の負担が生まれます。

  • 募集文を毎回ゼロから書いていて、急な欠員のときに時間がとれない
  • 初めて来る方が毎回入れ替わるため、同じ説明を口頭で繰り返している
  • 業務の手順書がないまま感覚で教えており、教える人によって内容がぶれる
  • 働いてくれた方への評価コメントが後回しになり、まとめて書く羽目になる
  • どの曜日・時間帯に人手が足りないのかを、感覚でしか把握できていない

いずれも「考える・書く・整える」作業です。まさに Claude Code が得意とする領域であり、下書きづくりと集計を任せて人は現場の判断に集中する分担が有効です。

3. タイミー運用で自動化できる5つの活用シーン

1. 募集文の作成と使い回せる型づくり

「土曜のランチ帯・ホール2名・接客経験不問」といった条件を渡すだけで、仕事内容・持ち物・服装・当日の流れが伝わる募集文の下書きを複数パターン作成できます。一度うまくいった募集文は型として保存しておけば、次回は条件だけ差し替えて数分で用意できます。応募が集まりにくい時間帯向けに、魅力の伝え方を変えた案を並べて比較することもできます。

2. 受け入れ手順書・当日マニュアルの整備

初めて来る方に必要な情報は、実はほぼ決まっています。入り口の場所、更衣室、タイムカードの押し方、休憩の取り方、任せる業務の手順。これらを箇条書きで渡すだけで、初見の方でも読める1枚の手順書に整えられます。口頭説明を紙に置き換えるだけで、現場の教える負担が大きく減ります。

3. 業務説明の言い換えと写真つき手順の下書き

「ドリンクを作る」だけでは伝わりません。器具の場所、氷の量、提供までの流れといった具体的な手順に分解した説明文を作れます。既にある社内資料を読み込ませれば、初見の方向けにやさしく書き直した版を用意することもできます。

4. 評価コメント・お礼メッセージの下書き

働いてくださった方への評価コメントを、その日の様子を数語伝えるだけで下書きにできます。良かった点を具体的に書いた文章は、また来てもらえる関係づくりにつながります。人手が足りる店ほど、こうした一言を欠かさず続けている店です。公開前に必ず人が確認する運用にすれば安心です。

5. 稼働データの集計と募集計画づくり

稼働実績をまとめたファイルを渡せば、曜日別・時間帯別に人手が足りていない箇所を集計し、読みやすいレポートに整えられます。数字が並んだ表ではなく「土曜の11時から14時が慢性的に不足しています」という文章にまとめてくれるため、店長交代があっても引き継ぎやすくなります。

5. 導入の4ステップ

  1. 目的を1つに絞る：最初から全部を自動化しようとせず、募集文の作成など一番つらい業務を1つ選びます。
  2. 材料を用意する：これまでの募集文、業務の手順メモ、稼働実績のデータを1つのフォルダにまとめます。過去にうまくいった募集文がそのまま「自店らしさ」の見本になります。
  3. Claude Code に日本語で指示する：「このフォルダの内容をふまえて、土曜ランチのホール募集文を3案作って」と伝えるだけです。出てきた案を見ながら「もう少し具体的に」「短くして」と調整します。
  4. 小さく試して広げる：2週間ほど運用して手応えがあれば、受け入れ手順書、評価コメント、稼働レポートへと対象を広げます。うまくいった指示は保存しておくと、次回から同じ品質で再現できます。

7. 運用上の注意点

  • 公開前は必ず人が確認する：時給、業務内容、持ち物、休憩の扱いなど条件に関わる部分は、自分の目で確かめてから掲載します。
  • 働く方の個人情報を扱わない：氏名や連絡先が含まれるデータは、そのまま読み込ませないよう運用ルールを決めておきます。
  • 労務のルールは自分で確認する：休憩時間や割増賃金など法令に関わる部分は、AIの出力をそのまま信じず所定のルールに沿って確認します。
  • 現場らしさを失わない：整いすぎた募集文はどの店でも同じに見えます。自店の雰囲気が伝わる一言を足すだけで応募の印象が変わります。
  • アカウント情報の管理：管理画面の認証情報は必要最小限の担当者のみが扱い、共有の範囲を明確にします。
